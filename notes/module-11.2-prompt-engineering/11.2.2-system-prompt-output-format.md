# 11.2.2 System Prompt：输出格式约束

## 一句话说清楚

**这里用一句白话解释"输出格式约束"是什么**（例如：输出格式约束就是告诉 AI 必须按指定格式返回数据，比如 JSON 或 Markdown 表格）

就是告诉AI，必须按照指定的格式，比如说JSON格式，Markdown格式等来返回数据；

## 核心要点

### 要点1：常见输出格式类型

**这里写常见的输出格式类型（如 JSON、Markdown 表格、代码块）以及每种格式的适用场景**

JSON对象：返回JSON用做数据源；
Markdown格式：用来写文档或者一些记录；
代码块：用于编码时返回响应的代码内容；

### 要点2：格式约束失败的常见原因

**这里写为什么 AI 有时候不按格式输出，以及如何提高格式约束的成功率**（例如：格式描述不够明确、示例不够清晰等）

1、格式描述不够明确，没有给示例或者示例不够清晰等；
2、AI的温度太高了，总添加创新内容；

## 我不确定的部分

**这里诚实写出你对输出格式约束还不太确定的点**（例如：不确定 JSON 格式约束是否需要配合 function calling；不确定格式约束和模型 temperature 的关系）

1、JSON格式约束不需要配合function calling；
2、有关系，temperature高了会导致AI创新能力提高，从而加入自己的创意点，而不严格按照格式约束；
