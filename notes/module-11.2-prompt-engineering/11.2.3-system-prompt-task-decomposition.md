# 11.2.3 System Prompt：任务分解指令

## 一句话说清楚

**这里用一句白话解释"任务分解指令"是什么**（例如：任务分解指令就是告诉 AI"复杂任务分几步走"，避免直接输出一团乱）

任务分解指令就是告诉AI，复杂任务应该分哪几个步骤，顺序是什么，避免AI自行发挥导致任务执行失败或无法达预期

## 核心要点

### 要点1：任务分解的常见模式

**这里写任务分解的常见模式**（例如：分析 → 方案 → 优先级；或者：输入校验 → 处理 → 输出格式化）

1、分析问题的根因是什么；
2、给出对应的解决方案或措施，以及相应的理由；
3、对比方案的优缺点，给出建议；
4、用户确定方案之后给出实施方案；

### 要点2：任务分解指令与 CoT 的关系

**这里写任务分解指令和 CoT（思维链）的区别和联系**（例如：任务分解是显式告诉 AI 步骤，CoT 是让 AI 自己推理中间步骤）

任务拆解是用户告诉AI，应该如何处理任务的实际步骤和方案；
CoT是AI自行对任务进行拆解推理的中间步骤；

## 我不确定的部分

**这里诚实写出你对任务分解指令还不太确定的点**（例如：不确定任务分解的步骤数量上限；不确定是否每一步都需要明确输出格式）

1、不确定上限；
