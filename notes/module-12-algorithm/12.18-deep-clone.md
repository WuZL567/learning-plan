# 12.18 手写深拷贝

## 一句话说清楚

（这里用你自己的话,一句话解释深拷贝是什么，和浅拷贝有什么区别）
深拷贝就是完全的复制一个对象，不是对象的引用，而是完整的新对象，和旧对象互不影响；
和浅拷贝的区别在于，能处理多层的对象，能处理各种类型的拷贝，不影响旧的数据；

## 核心要点一：基础版深拷贝的实现思路

（这里写只处理对象和数组的深拷贝，核心逻辑是什么）
function deepClone1(obj) {
    // 基本类型直接返回自身
    if (obj == null || typeof obj !== 'object') return obj;

    // 数组和对象类型
    const result = Array.isArray(obj) ? [] : {};
    for (const key of Reflect.ownKeys(obj)) {
        // 递归
        result[key] = deepClone1(obj[key]);
    }
    return result;
}

## 核心要点二：完整版深拷贝要处理的边界情况

（这里列出循环引用、特殊类型（Date/RegExp/Map/Set）、基本类型、null 等情况，每种怎么处理）
基本类型和null，都直接返回自身就好；
特殊类型需要具体类型具体处理；
function deepClone2(obj, map = new WeakMap()) {
    // 基本类型，直接返回自身
    if (obj == null || typeof obj !== 'object') return obj;
    // 已经存在的映射直接返回
    if (map.has(obj)) return map.get(obj);
    // Date类型
    if (obj instanceof Date) return new Date(obj);
    // RegExp类型
    if (obj instanceof RegExp) return new RegExp(obj.source, obj.flags);
    // Map类型
    if (obj instanceof Map) {
        const cloneMap = new Map();
        map.set(obj, cloneMap);
        obj.forEach((value, key) => {
            cloneMap.set(deepClone2(key, map), deepClone2(value, map));
        });
        return cloneMap;
    }
    // Set类型
    if (obj instanceof Set) {
        const cloneSet = new Set();
        map.set(obj, cloneSet);
        obj.forEach((value) => {
            cloneSet.add(deepClone2(value, map));
        });
        return cloneSet;
    }
    // 数组或对象
    const cloneObj = Array.isArray(obj) ? [] : {};
    map.set(obj, cloneObj);
    for (const itemKey of Reflect.ownKeys(obj)) {
        cloneObj[itemKey] = deepClone2(obj[itemKey], map);
    }
    return cloneObj;
}

## 我不确定的部分

（这里诚实写出你没完全搞懂的点，比如"为什么用 WeakMap 而不是 Map"、"Symbol 类型的 key 怎么处理"等）
1、weakMap可以自动清理内存，比Map更优；
2、你说的怎么处理是什么意思？
使用 Reflect.ownKeys，返回所有的自身属性的key，（包括String Key + Symbol key + 不可枚举的Key），不包括原型链；
但是用for...in会遍历可枚举属性（包括原型链），不包括Symbol；
使用Object.keys会遍历可枚举的String key，不包括Symbol和原型链；
