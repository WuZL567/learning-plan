# 6.5 localStorage 特性

冲刺模式模板：一句话说清楚 + 三个要点 + 不确定的点

## 一句话说清楚

这里用一句白话写：localStorage 是什么、数据什么时候会消失。
是一种存在浏览器本地的持久化存储方式，数据不会过期，只有主动清理才会消失；

## 三个要点

**要点1：基本特性**
写清楚：
- 容量多大？存的是字符串还是对象？
5MB的字符串；
- 数据什么时候被清掉（关浏览器/关标签页/重启电脑分别是什么情况）？
不会自动清理，只有手动删除才会被清掉；
- 哪些 API（setItem/getItem/removeItem/clear）？存对象要不要 JSON.stringify？
setItem：设置存储的值；
getItem：获取存储的值；
removeItem：移除指定的存储的值；
clear：清空存储；
存对象需要JSON.stringify转成字符串存进去，拿出来时需要JSON.parse恢复成对象；

**要点2：作用域（重点）**
想两个场景写答案：
- `a.example.com` 存的数据，`b.example.com` 能读到吗？为什么？
不行，需要同源才可以读取，必须相同协议，相同域名，相同端口号；
- `a.example.com` 存的数据，`a.example.com/admin` 这个路径能读到吗？
可以；
- 同一个域的不同标签页之间，localStorage 是共享的吗？
是的；

**要点3：你不能用 localStorage 做什么**
写清楚三个坑：
- 存敏感信息（Token/密码）有什么风险？
直接暴露，任何能在该页面执行 JS 的脚本都能读；
- 存的数据有格式约束吗？存的东西会被用户改吗？
存字符串，会被修改；
- 跨标签页实时同步数据，localStorage 能主动通知别的页面吗？（提示：storage 事件）
可以，可以通过监听storage事件来接收通知；

## 三层追问（验收时口答，不用写）

1. 白话复述：30 秒讲清楚 localStorage 是什么、什么时候清。
localstorage是一种存在浏览器的本地化存储方式；主动删除时清理；
2. 对比理解：localStorage 和 sessionStorage 的区别（这个 6.6 会细讲，这里先答你能想到的）。
localstorage是本地化存储，sessionstorage是会话级存储；
localstorage关闭标签页和浏览器都不会清理，除非主动清理；
sessionstorage则关闭会话标签页就会被清理；
3. 场景应用：把用户信息存 localStorage 里，发现另一个域名也能读到，可能吗？为什么？
不可能，因为必须同源才能共享localstorage的信息。同源必须是：同一个协议，同一个域名，同一个端口；
