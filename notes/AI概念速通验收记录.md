## 验收题目与答题情况

### 第一题：结构化输出（基础理解）

**问**：Prompt 约束 vs API 层面强制+Pydantic 校验，有什么区别？哪种更可靠？

**学生答**：做法 A 是通过 Prompt 来约束，做法 B 是在 API 的层面限制，做法 B 更可靠，强制 API 按照约定的格式返回，并且增加工具来校验返回格式，不符合就不会通过。

**评判**：✅ 正确。补充：做法 A 可能返回多余文字（如"这是提取的信息：{...}"），做法 B 保证纯 JSON。

---

### 第二题：Function Calling（核心流程）

**问**：用户问"我的订单 12345 发货了吗？"，描述 Function Calling 完整流程。

**学生答**：用户提问 → LLM 分析应该使用工具清单中哪一个工具 → LLM 调用工具 → 工具触发后端代码 → 后端代码执行后返回结果给 LLM → LLM 分析结果后组织语言返回给用户。

**评判**：⚠️ 概念对，但有误解。**LLM 不会真正调用工具**，它只返回 JSON 告诉你"建议调用哪个工具，参数是什么"，你的后端代码负责真正执行。（扣 0.2 分）

**正确流程**：
1. 用户提问 → LLM 分析
2. LLM 返回 `{"tool_calls": [{"function": {"name": "query_order", "arguments": "{\"order_id\": \"12345\"}"}}]}`
3. 你的代码解析 JSON，真正调用 `query_order` 函数
4. 你的代码把工具结果返回给 LLM
5. LLM 生成用户能看懂的回复

---

### 第三题：Function Calling（权限控制）

**问**：攻击者劫持 LLM 让它执行 `delete_user(user_id=888)`，工具白名单能防住吗？

**学生答**：不能成功。在工具清单中不要有危险操作的工具，比如申请退款和删除用户。

**评判**：✅ 正确。补充：申请退款可以改成"提交待审批"而不是直接执行；删除用户绝对不能放到工具清单。

---

### 第四题：RAG（核心概念）

**问**：为什么不直接把 500 个文档都塞到 Prompt 里？RAG 的做法是什么？

**学生答**：LLM 的上下文窗口限制，无法容纳大文件。RAG 是检索增强生成，将文档拆分转成向量，存在向量数据库，然后拆分用户的问题为向量，在数据中查找匹配的文档。

**评判**：⚠️ 正确，但流程差最后一步。找到文档后要**把文档片段拼到 Prompt 里，让 LLM 基于这些文档回答**。（扣 0.2 分）

---

### 第五题：Embedding（关键概念）

**问**：什么是向量？为什么"如何报销"和"费用申领流程"能被 RAG 检索到？

**学生答**：Embedding 就是向量，将文本转成一串数字表示向量，因为相似文本转成的数字也接近。传统关键字检索就直接匹配有没有对应的字符串，但是 Embedding 是将字符串转成了数字，数字接近表示它们的意思差不多。

**评判**：✅ 完全正确！

---

### 第六题：RAG vs Function Calling（场景区分）

**问**：
- 用户 A："你们的退货政策是什么？"
- 用户 B："我的订单 12345 发货了吗？"

分别适合用哪个技术？

**学生答**：查找退货政策时用 RAG，查询订单状态时用 Function Calling。因为退货政策就是一个文本的内容描述，但是订单状态需要从数据库中查找。

**评判**：✅ 完全正确！总结：知识型问题 → RAG，操作型任务 → Function Calling。

---

### 第七题：RAG 的局限性

**问**：知识库里没有相关文档会怎样？RAG 成本比纯 LLM 高还是低？

**学生答**：检索不到的 LLM 就不知道。RAG 的成本更高，除了 LLM，还包括 embedding 模型调用 + 向量检索。

**评判**：✅ 正确。补充：应该在 Prompt 里告诉 LLM"如果参考资料里没有，请说'我不知道'，不要瞎编"，避免幻觉。

---

### 第八题：结构化输出 + Function Calling 组合

**问**：用户问"帮我查上个月销售数据，并生成柱状图"，用到哪些技术？

**学生答**：需要。查询销售数据时用 Function Calling 调用查询工具；生成柱状图是用户要求，在 prompt 中，所以会返回柱状图的内容格式。

**评判**：⚠️ 基本对，但"生成柱状图"这里必须用结构化输出。LLM 要返回严格的 JSON（图表配置），前端用 ECharts 渲染，不能返回自然语言描述。（扣 0.2 分）

---

### 第九题：实际项目架构（综合题）

**问**：企业 AI 助手需求：
1. 查公司政策
2. 查考勤记录
3. 提交请假申请
4. 返回结构化数据给前端

分别用到哪些技术？

**学生答**：
1. RAG，知识库问答
2. Function Calling，查询考勤
3. 结构化输出（返回表单数据）+ Function Calling（调用后端提交）
4. 结构化输出

**评判**：✅ 非常好！技术选型准确。

### 需要记住的关键点
