# 4.15 DNS 解析过程

## 一句话说清楚
（用一句白话解释 DNS 解析是什么，比如"DNS 解析就是把域名翻译成 IP 地址的过程"）
就是将域名解析成服务器知道的IP地址；

## 核心要点一：完整查询链路（7 层）
（按顺序写出 DNS 查询的 7 层缓存/服务器：浏览器缓存 → 操作系统缓存 → 路由器缓存 → 本地 DNS 服务器 → 根域名服务器 → 顶级域名服务器 → 权威域名服务器。每层简短说明作用）
DNS查询链路氛围两大层，一个是本地，一个是服务器；本地的那一层是递归查询，会直接给结果；服务器那一层则是迭代查询，一层一层的指引下一层查谁；
本地递归查询：浏览器缓存 -> 操作系统（hosts文件/DNS）缓存 -> 路由器缓存 -> 本地DNS服务器；
服务器迭代查询：本地DNS服务器 -> 根域名服务器(.) -> 顶级域名服务器(.com) -> 权威域名服务器(baidu.com)返回最终IP；

## 核心要点二：递归查询 vs 迭代查询
（写清楚浏览器到本地 DNS 是递归查询（"帮我查到底"），本地 DNS 到根/顶级/权威是迭代查询（"告诉我下一步问谁"）。可以用类比，比如递归查询像"找代购"，迭代查询像"自己一步步问路"）
1、递归查询：直接递归直到查询到结果；
 - 浏览器缓存 -> 操作系统缓存 -> 路由器缓存 -> 本地DNS服务器；
2、迭代查询：每一层都不告诉你答案，只是指引你下一层去哪查；
 - 本地DNS服务器 -> 根域名服务器（去.com查） -> 顶级域名服务器（去baidu.com查） -> 权威域名服务器（告知你最终的IP地址是什么）；
