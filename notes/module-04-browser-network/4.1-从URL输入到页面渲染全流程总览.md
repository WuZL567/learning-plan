# 4.1 从URL输入到页面渲染全流程总览

日期：2026-08-31

## 一句话说清楚

用自己的话一句话解释"从输入 URL 到页面渲染"整个流程是什么。

> 提示：把整个流程按"网络阶段 → 浏览器拿到数据后的解析阶段 → 渲染阶段"说清楚。目标是面试官听完觉得你脑子里有这张完整的地图，而不是零散的点。

输入URL，DNS解析将域名解析成服务器IP地址，然后TCP三次握手和服务器建立连接，TSL建立加密HTTP通道，发送HTTP请求，服务器返回HTML文件以及CSS，JS等资源；
然后解析HTML为DOM树，解析CSS为CSSOM样式树，再将DOM树和CSSOM样式树组合渲染绘制；

## 三个要点

把整个流程拆成三个关键环节，每个环节写 1-2 句自己的话讲清楚这个环节是干什么的、包含哪些步骤。

**要点一：网络请求阶段（从输入URL到拿到响应）**

> 提示：这里要写出完整顺序——DNS解析 → TCP三次握手 → TLS握手（HTTPS）→ 发HTTP请求 → 服务器返回。重点想清楚：DNS 解析拿到的是什么？TCP 握手是为什么服务的？
DNS解析：拿到域名对应的服务器IP地址；
TCP三次握手：和服务器建立连接；
TLS握手：和服务器建立HTTPS加密通道；
服务器返回：HTML文件+CSS+JS资源；

**要点二：HTML/CSS/JS 解析阶段（拿到字节流之后）**

> 提示：浏览器拿到 HTML 后发生了什么？DOM 树和 CSSOM 是怎么构建的？遇到 <script> 和 <link> 会怎么样？（提示：JS 会阻塞什么，CSS 会阻塞什么，两个阻塞的效果不一样）
将HTML解析成DOM树，将CSS解析成CSSOM样式树；
JS阻塞DOM解析，因为JS可能修改DOM，需要等待JS执行完；
CSS阻塞DOM渲染，不阻塞DOM解析，因为CSS不会修改DOM，但是会影响样式；

**要点三：渲染阶段（从树到屏幕像素）**

> 提示：渲染管线的大致顺序——布局 → 绘制 → 合成。用自己的话讲清楚"回流、重绘、合成"大致对应渲染管线的哪个环节即可，不用展开细节。
布局Layout：元素在界面上的布局位置和尺寸大小，回流发生在这；
绘制Paint：把元素转成像素，重绘发生在这；
合成：GPU拼装合成；
