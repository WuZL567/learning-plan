## 一句话说清楚

（用一句大白话解释watch是什么，和watchEffect有什么本质区别？）

watch是监听指定值变化并且执行回调的机制，watch支持拿到新值和旧值，支持配置深度监听和立即执行；

## 核心要点1：watch的三种监听方式

（讲清楚watch可以监听哪三种数据源？ref、reactive、getter函数分别怎么写？deep和immediate参数有什么用？）

支持监听 ref，reactive，getter 三种数据源；
 - 监听ref：直接传xxx（不用包getter函数），或者() => xxx.value
 - 监听reactive对象的某个属性：() => state.count（必须用getter函数）
 - 监听reactive整个对象：直接传state，但默认是深度监听（隐式deep:true）

deep：支持深度监听，对于对象多层时，支持监听对象深层的数据变化；
immediate：支持立即执行，默认是懒执行，设置为true可以立即执行；

## 核心要点2：watch vs watchEffect的区别

（从依赖收集、新旧值、执行时机三个角度对比，各自适合什么场景？）

依赖收集：watch显式指定监听的数据源，watchEffect不显式指定，直接自动收集回调用到的参数；
新旧值：watch有新旧值，watchEffect没有；
执行时机：默认懒执行，支持设置immediate为true来立即执行，watchEffect支持立即执行；

## 我的理解中不确定的部分

（诚实写出你没完全搞懂的点，比如：为什么watch reactive对象需要deep:true？watch多个数据源怎么写？watch的返回值是干什么的？）

1、因为对象可能存在深度的层次，需要deep参数来深度监听；
2、写数组形式；
watch([source1, source2], ([new1, new2], [old1, old2]) => {
  // 回调接收两个数组
})
3、watch返回一个停止监听的函数，调用它可以手动停止监听：
  const stopWatch = watch(source, callback)；
  // 某个时机停止监听
  stopWatch()
  - 这在组件卸载前或条件性监听时很有用；
