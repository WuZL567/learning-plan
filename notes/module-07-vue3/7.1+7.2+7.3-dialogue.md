## 验收过程

### 学生提交的笔记核心内容

**7.1 响应式原理：**
- 一句话：利用Proxy拦截对象，在get时收集依赖，在set时触发更新
- Proxy vs Object.defineProperty：Proxy监听整个对象，Object.defineProperty监听单个属性，无法监听新增属性、数组下标、属性删除
- 依赖收集：组件渲染时访问属性触发getter，getter记录依赖关系存在映射表中；赋值时触发setter，setter查映射表通知组件更新
- 不确定点：嵌套对象怎么处理、数组怎么监听、依赖存在哪个数据结构

**7.2 Composition API：**
- 一句话：函数式的组件逻辑组织方式，用setup函数代替options对象，把相关逻辑整合聚在一块
- setup函数：生命周期在beforeCreate之后created之前，返回对象，不能访问this，替代了beforeCreate/created
- 三大优势：逻辑复用（useXxx函数）、类型推断（更好支持TS）、代码组织（按功能拆分）
- 不确定点：setup和script setup区别、ref和reactive选哪个、能否混用

**7.3 生命周期：**
- 一句话：Vue3去掉beforeCreate/created，其他钩子加on前缀，执行时机不变
- 常用钩子：setup（定义变量初始化）、onMounted（渲染更新界面）、onBeforeUnmount（取消监听清理定时器）
- 常见坑：DOM操作放onMounted避免数据更新不上、定时器在onBeforeUnmount清理避免内存占用
- 不确定点：onBeforeUpdate/onUpdated用途、父子组件生命周期顺序、Keep-alive生命周期

**第二层：对比理解**

导师：Proxy和Object.defineProperty的区别是什么？
学生：Proxy监听整个对象，Object.defineProperty监听单个属性，无法监听新增属性、数组下标、属性删除
✅ 正确，三个痛点都讲到了

导师：setup和script setup有什么区别？
学生：好像没有本质区别
❌ 错误
**正确答案：** setup()函数需要手动return暴露给模板，script setup是语法糖自动暴露顶层变量；script setup编译后性能更好代码更简洁；script setup中无法使用render函数

导师：父子组件生命周期执行顺序是怎样的？
学生：父setup → 父onBeforeMount/onMounted → 子setup → 子onBeforeMount/onMounted
⚠️ 部分错误
**正确答案：** 父setup → 父onBeforeMount → 子setup → 子onBeforeMount → **子onMounted → 父onMounted**（子组件必须完全挂载完，父组件才算挂载完，洋葱模型）

**第三层：场景应用**

导师：如果reactive包装的对象有3层嵌套，Vue3怎么监听深层属性？
学生：嵌套对象不知道怎么处理
**正确答案：** Vue3采用懒代理（lazy proxy），只在访问嵌套对象时才递归创建Proxy。比如state.user.profile.name，第一次访问state.user时才给user对象套Proxy，访问user.profile时才给profile套Proxy，避免一次性递归整个对象树造成性能浪费

导师：为什么定时器不清理会内存泄漏？
学生：组件销毁前清理定时器避免内存占用
✅ 正确，补充：组件销毁后定时器回调仍持有组件实例的闭包引用，导致组件无法被GC回收

导师：Keep-alive组件的生命周期有什么特殊？
学生：keep-alive没有onBeforeUnmount/onUnmounted
⚠️ 不完整
**正确答案：** 被Keep-alive缓存的组件有专属钩子onActivated（组件激活时）和onDeactivated（组件失活时），用来替代mount/unmount做初始化/清理工作

**需要补充的知识点：**

1. **ref vs reactive选型：** 推荐统一用ref，因为ref解构不丢失响应式（.value显式访问）、reactive解构会丢失响应式（需要toRefs包装）、ref可以重新赋值整个对象而reactive不行

2. **依赖存储结构：**
   ```
   targetMap (WeakMap)
     └─ target对象 → depsMap (Map)
          └─ 属性key → dep (Set)
               └─ 存储effect函数
   ```

3. **数组监听：** Vue3的Proxy可以直接监听数组下标和length变化，不需要像Vue2那样重写数组方法
