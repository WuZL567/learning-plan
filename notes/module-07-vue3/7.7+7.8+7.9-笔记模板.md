## 技术点 7.7：watchEffect 与 watch 的区别

### 一句话说清楚
<!-- 这里用你自己的话解释：watchEffect 和 watch 最本质的区别是什么？ -->
1、watch需要指定依赖数据，watchEffect不指定，完全自动收集依赖的数据，类似computed；
2、watch默认是懒执行，需要immediate为true才会立即执行，但watchEffect就是立即执行的；
3、watch支持获取新旧值，但是watchEffect不支持获取新旧值，在回调中才能获取新的值；

### 核心要点一：依赖收集方式的差异
<!-- 这里写：watch 是怎么指定监听源的？watchEffect 是怎么自动追踪依赖的？举一个具体例子 -->
const count = ref(0);
watch(count, (newValue, oldValue) => {
    console.log("newValue: ", newValue);
    console.log("oldValue: ", oldValue);
});

watchEffect(() => {
    console.log(count.value + 1);
});

### 核心要点二：使用场景对比
<!-- 这里写：什么时候用 watch？什么时候用 watchEffect？各举一个实际场景 -->
需要实际使用到指定数据的新旧值的时候，就用watch；
需要类似computed这样自动收集的时候，就用watchEffect；

## 技术点 7.9：Diff算法完整流程

### 一句话说清楚
<!-- 这里用你自己的话解释：Diff算法是干什么的？为什么能把O(n³)优化到O(n)？ -->
对比虚拟DOM新旧数据之间差异；
同层比较，不跨层级 + 双端指针；

### 核心要点一：同层比较原则
<!-- 这里写：为什么只做同层比较不跨层比较？这个假设在实际开发中成立吗？ -->
只比较同一层级的节点，不同层级视作差异，直接删除重建；

### 核心要点二：双端对比的四种情况
<!-- 这里写：头头、尾尾、头尾、尾头四种比较分别对应什么场景？用列表的增删改移动来举例 -->
头头比较：新旧数组的头指针的节点是同一个，复用；
尾尾比较：新旧数组的尾指针的节点是同一个，复用；
头尾比较：旧的头指针和新的尾指针是同一个节点，说明节点往后移动了，复用并移动；
尾头比较：新的头指针和旧的尾指针是同一个节点，说明节点往前移动了，复用并移动；
