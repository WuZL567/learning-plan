# 3.3 盒模型（标准盒模型 vs IE盒模型）

## 第一部分：一句话说清楚

用一句白话解释什么是盒模型。这里写"盒模型是……"，一句话讲完，不要展开。

盒模型是用来表述一个元素实际占位宽度大小的规则，分为标准盒模型和怪异盒模型两个；

## 第二部分：核心原理

用类比或图解讲清楚。这里写：
1. 标准盒模型（content-box）下，元素的 width 属性到底管哪一段？元素实际占的总宽度怎么算？
[ margin [ border [ padding [ content ] padding ] border ] margin ]
content-box下，width表示content的宽度；元素实际占的总宽度包括 content+padding+border；

2. IE 盒模型（border-box）下，width 又管哪一段？总宽度怎么算？
[ margin [ border [ padding [ content ] padding ] border ] margin ]
border-box下，width表示content + padding\*2 + border\*2的宽度；元素实际占的总宽度就是width设置的值；

3. 画一个对比图（可以用字符画或者表格），标出两个模型下 content / padding / border 在 width 内的差别
content-box下，width的宽度就是content的宽度，额外的包括padding和border；
border-box下，width的宽度就是content的宽度+2个padding的宽度+2个border的宽度；

4. box-sizing 属性怎么设置？全局 reset 常用写法是什么？
{ box-sizing: content-box; } // 标准盒模型
{ box-sizing: border-box; } // 怪异盒模型/IE盒模型
全局reset方法是：* { box-sizing: border-box; } // 因为默认是标准盒模型，所以重制为IE盒模型，这样设置宽度width时，就是设置看到的占位像素；

## 第三部分：和 XX 的区别或关系

这里写以下对比：
1. content-box 和 border-box 的区别（用一个具体例子：比如 width: 100px、padding: 20px、border: 5px 时，两个模型下元素总宽度分别是多少，要算出具体数字）
content-box的元素实际占位宽度：就是100px + 2*20px + 2*5px = 150px = content的宽度；
border-box的元素实际占位宽度：就是100px，但是100px - (2*20px + 2*5px) = content的宽度 = 50px；

2. margin 在两种盒模型下有什么区别吗？margin 算不算盒模型的一部分？它影响父容器子元素的什么？
没区别，不算盒模型的一部分，子元素的外边距；

## 第四部分：我的理解中不确定的部分

诚实写出没完全搞懂的点。这里写：
1. 什么场景下必须用 border-box？什么场景反而应该用 content-box？
正常设置width就是占位宽的时候，或者用百分比来划分区域宽度时，就用border-box；
不知道什么时候一定要用content-box；

2. 有没有遇到过明明设了 width 却撑爆布局的情况？回想一下当时是哪个模型在捣乱。
没有设置border-box的模型时，同时又存在padding和border的宽度，所以撑爆了布局；

3. 其他你拿不准的细节（比如 input、textarea、button 的默认 box-sizing 是什么）。
默认的都是content-box；
