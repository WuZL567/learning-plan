# 3.14 CSS 选择器优先级计算规则

冲刺模式模板：一句话说清楚 + 三个要点 + 不确定的点

## 一句话说清楚
基本分为4类，按照权重从高到低依次是：内联样式 -> ID -> class/属性选择器（[type=xxx]）/伪类（:hover） -> 元素（div）/伪元素（::before），特殊的包括：最高级（!important）最低级（通配符*）

## 三个要点

**要点1：优先级怎么算**
这里写：优先级的四个位分别是什么（内联样式 / ID / 类·属性·伪类 / 类型·伪元素），怎么逐位比较。
内联样式 / ID / 类·属性·伪类 / 类型·伪元素，从左到右依次逐位对比，已经分出胜负的不需要继续对比后面的位，不存在进位

再自己算两个例子：`#app .box p` 和 `div .nav a:hover`，把每一位的计数写出来。
`#app .box p`：     内联（0）ID（1）类·属性选择器·伪类（1）元素·伪元素（1） -> (0,1,1,1)
`div .nav a:hover`：内联（0）ID（0）类·属性选择器·伪类（2）元素·伪元素（2） -> (0,0,2,2)

**要点2：进位陷阱**
这里写：为什么 10 个类选择器打不过 1 个 ID 选择器（逐位比较、不进位）。
想一个反例：`body .wrap .box .item a`（4 个类+1 个标签）vs `#title`，谁赢？为什么？
`#title`赢，因为`#title`是ID，ID对比的时候已经赢了，后面的对比就不再有用，不支持进位对比；

**要点3：特殊情况**
这里写三个规则的口诀式结论：
- `!important` 的位置在哪（凌驾于内联样式吗？）
在权重最高的位置，凌驾于内联之上；
- `:not()` 本身计不计权重，括号里的选择器计不计
本身不计权重，而是括号内的选择器计算权重；
- 通配符 `*` 的权重是多少
0

## 我的理解中不确定的部分

这里诚实写出还没完全搞懂的点，比如：`style=""` 内联和 `!important` 同时出现谁赢？`:hover` 和 `.active` 谁大？动态加载样式（JS 插入）会影响优先级吗？
1、`!important`赢，凌驾于内联样式之上；
2、一样大，class（.active）和伪类（:hover）都是第三级的权重，但是看他们加载顺序前后关系来判断谁生效；
3、会影响优先级，有一些权重一样的样式，后加载的会覆盖前面的样式；

## 三层追问（验收时口答，不用写）

1. 白话复述：30 秒讲清楚 CSS 优先级是什么
CSS优先级是CSS用来判断哪些样式生效哪些样式被覆盖的规则，按照四位计数以及逐位对比的方式进行；
四位计数的顺序为（内联样式 -> ID -> class/属性选择器[type=xxx]/伪类:hover -> 元素div/伪元素::before）；

2. 对比理解：优先级和层叠（cascade）是一回事吗？和"后面的样式覆盖前面的"是什么关系？
不是一回事，优先级是不同权重之间的优先级关系，而层叠是相同权重下，后加载的样式会覆盖前面的样式；

3. 场景应用：现在有个 bug——按钮红色样式不生效，被蓝色的样式覆盖了。你怀疑是优先级问题，怎么排查？
先注释蓝色样式，如果红色生效，再比较两个样式的权重；
或者可以直接给红色样式加上!important，如果生效，则确实是权重问题；
