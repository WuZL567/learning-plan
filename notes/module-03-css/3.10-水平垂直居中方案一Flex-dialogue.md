日期：2026-08-28

---

## 一、教学过程

### 为什么需要它

你在 Vue 项目里天天遇到这种事：一个登录弹窗、一个 loading 遮罩、一个空状态提示，都要"放到屏幕正中间"。这个需求做了 5 年，但很多人是背代码——`.container { display: flex; justify-content: center; align-items: center; }` 抄下来能用，被问到"这俩属性到底管哪个方向"就卡壳。

面试官特别爱问这个，因为它是 flex 主轴/交叉轴理解的最直接检验。你 3.6、3.7 已经学过主轴和交叉轴属性，3.8 也实战过了，今天就是把学到的收拢成一个高频场景：**居中**。

### 一句话说清楚

在 flex 容器上同时设置 `justify-content: center` 和 `align-items: center`，子元素就在两个方向上都居中——一个管主轴，一个管交叉轴。

### 核心原理

不重复讲主轴交叉轴基础了，你 3.6/3.7 学过。这里只讲三个你可能没想透的点：

**第一点：谁管水平、谁管垂直，取决于 flex-direction**

默认 `flex-direction: row`，主轴是水平方向，所以：
- `justify-content: center` → 水平居中
- `align-items: center` → 垂直居中

但如果你写的是 `flex-direction: column`（比如弹窗内部垂直排列的布局），主轴变成垂直方向，两个属性的分工**跟着互换**：
- `justify-content: center` → 垂直居中
- `align-items: center` → 水平居中

这就是面试陷阱：不要死记"justify 管横、align 管竖"，要记"justify 管主轴、align 管交叉轴"。

**第二点：为什么 flex 方案比绝对定位简单**

绝对定位居中（3.11 会学）要 `position: absolute` + `top: 50%` + `transform: translate(-50%, -50%)`，子元素尺寸变了还得重新算。Flex 方案不需要知道子元素宽高，只要容器有尺寸就行——就像往抽屉里放东西，抽屉多大都能放正中间。

**第三点：一个隐藏的坑——容器高度必须是确定的**

`align-items: center` 在交叉轴方向分配的是**多余空间**。如果容器 `height: auto`（高度由内容撑开），垂直方向没有多余空间，居中就无从谈起——子元素会把容器撑满，跟没设一样。这点你练习里要自己验证。

类比：`justify-content` 和 `align-items` 像是两个方向的搬运工。抽屉（容器）有多余空间，搬运工才有活儿干；抽屉刚好和物品一样大，搬运工只能干瞪眼。

## 二、验收过程

### 学生提交的代码核心内容

学生提交了 `src/module-03-css/3.10-水平垂直居中方案一Flex/index.html`，CSS 部分：

```css
.container {
  display: flex;
  /* 当width为50%时，水平居中是否生效取决于容器宽度是否大于中间box的宽度，如果大于则生效，否则会撑满 */
  width: 600px;
  /* 当height为auto时，align-items:center不会出现垂直居中，因为容器高度被内部box撑满了 */
  height: 400px;
  background-color: cadetblue;
  /* 控制主轴方向，当前flex-direction默认是row，所以主轴是横着的，所以这个是控制水平居中 */
  justify-content: center;
  /* 控制交叉轴方向，当前flex-direction默认是row，所以交叉轴是竖着的，所以这个控制的是垂直居中 */
  align-items: center;
}

.box {
  width: 200px;
  height: 120px;
  background-color: bisque;
}
```

### 逐项评判

**justify-content 注释（"控制主轴方向，当前flex-direction默认是row，所以主轴是横着的，所以这个是控制水平居中"）**

✅ 正确。准确抓住了"justify 管主轴、方向取决于 flex-direction"这个核心，没有死记"justify 管横"。理解符合教学要求。

**align-items 注释（"控制交叉轴方向，当前flex-direction默认是row，所以交叉轴是竖着的，所以这个控制的是垂直居中"）**

✅ 正确。与 justify-content 形成对称理解，交叉轴概念清晰。

**height: auto 边界注释（"当height为auto时，align-items:center不会出现垂直居中，因为容器高度被内部box撑满了"）**

✅ 正确。这是本次练习的核心边界问题，学生回答准确：容器高度 auto 时由内容撑开，交叉轴没有多余空间，垂直居中失效。抓住了"align-items 分配的是多余空间"的本质。

**width 边界注释（"当width为50%时，水平居中是否生效取决于容器宽度是否大于中间box的宽度，如果大于则生效，否则会撑满"）**

⚠️ 部分正确。判断方向正确（容器有多余空间，居中才成立），但"否则会撑满"表述不精确：
- 容器比 box 窄时，flex 子项默认 `flex-shrink: 1`，box 会被**压缩**到容器宽度，不是"撑满"
- 只有显式设 `flex-shrink: 0`，box 才保持 200px 并溢出容器
- 实际是三种情况：居中 / 被压缩 / 溢出，而不是"居中 / 撑满"两种
