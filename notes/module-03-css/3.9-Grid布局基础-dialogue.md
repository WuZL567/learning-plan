日期：2026-08-28

## 一、教学过程

### 为什么需要它

你前面学的 Flex 是**一维**布局——它只能管一个方向，主轴要么横要么竖。就像排队：大家站成一排或者一列，你要排成"方阵"就得把队列套队列。

Grid 是**二维**布局——直接在一个平面上画格子。就像 Excel 表格：先定好几行几列，然后每个格子各自安排。像这种经典页面结构：

```
┌──────────┬──────────────────┐
│  header（通栏）               │
├──────┬───┴─────────┬────────┤
│ 侧边栏 │   内容区      │ 广告栏 │
├──────┴─────────────┴────────┤
│  footer（通栏）               │
└─────────────────────────────┘
```

Flex 写这种布局要嵌套好几层加宽度计算，Grid 一行声明就完事。面试时 Grid 是加分项，实际项目里也用得上（后台管理系统、卡片墙、大屏）。

### 一句话说清楚

Grid 把容器分成**行（row）和列（column）的二维网格**，子元素像单元格一样被"放"进网格里，而你只需要告诉它每个子元素占哪几行几列。

### 核心原理

**两个角色**：
- 容器（grid container）：`display: grid`
- 网格线（grid line）：画网格的线，从 1 开始编号。**线，而不是格子，才是定位的基准**

**四组核心属性**（先记容器上的两组）：

```css
/* 容器上：定义网格的"骨架" */
display: grid;
grid-template-columns: 100px 1fr 2fr;  /* 列：3列，第二列是第三列的一半 */
grid-template-rows: 80px auto;         /* 行：第一行固定80px */

/* 容器上：控制格子间间距（只加间距，不参与布局计算） */
gap: 16px 24px;  /* 行间距 16px，列间距 24px */
```

**关键单位 `fr`（fraction，分数）**：像 Flex 的 `flex-grow`，按比例瓜分剩余空间。`1fr 2fr` = 第二列是第一列的两倍宽。

**子元素上**：用网格线编号指定占位：

```css
/* 从第1条竖线到第3条竖线，从第1条横线到第2条横线 */
.item {
  grid-column: 1 / 3;   /* 竖线：第1条到第3条 */
  grid-row: 1 / 2;      /* 横线：第1条到第2条 */
}
```

**类比 Vue 经验**：`grid-template-columns` 就像给 el-table 定义列配置，`fr` 就像 flex:1 的伸缩因子，`grid-column: 1 / 3` 就像合并单元格（rowspan/colspan）。

### 你需要做什么

用 Grid 实现圣杯布局（头部通栏 + 左侧边栏 + 主内容 + 右侧边栏 + 底部通栏），**必须用 Grid 实现**，不需要写 Flex。

- 用 `grid-template-columns` 定义三列（侧边栏固定宽度，中间自适应）
- 用 `grid-template-rows` 定义三行（头部和底部固定，中间自适应）
- 用 `grid-column` / `grid-row` 让 header 和 footer 跨整行
- 用 `gap` 控制间距
- 每个区域用不同背景色区分，方便验证

初始文件已创建：`src/module-03-css/3.9-Grid布局基础/index.html`

### 验收标准

1. 容器设置 `display: grid`
2. `grid-template-columns` 定义三列：sidebar 固定 200px、main 用 `1fr` 自适应、aside 固定 200px
3. `grid-template-rows` 定义三行：header 固定 60px、中间 `1fr`、footer 固定 60px
4. header 和 footer 用 `grid-column: 1 / 4`（或 `1 / -1`）跨整行
5. `gap: 10px` 设置间距
6. 五个区域不同背景色，整体占满 100vh

## 二、验收过程

### 第一次提交（2026-08-28）

学生提交 `src/module-03-css/3.9-Grid布局基础/index.html`，说："写完了，验收 3.9"。

**学生代码的核心内容：**

```css
body {
  display: grid;
  /* 定义三列，从左至右依次是200px，自适应，200px */
  grid-template-columns: 200px 1fr 200px;
  /* 定义三行，从上往下依次是60px，自适应，60px */
  grid-template-rows: 60px 1fr 60px;
  /* 行间距列间距都是10px */
  gap: 10px 10px;
  width: 100%;
  /* 页面高度100vh */
  height: 100vh;
}

.header, .footer { grid-column: 1 / 4; }
```

- 直接在 body 上开 grid，5 个区域直接作为 body 的子元素（header、sidebar、main、aside、footer）
- 三列 `200px 1fr 200px`，三行 `60px 1fr 60px`
- header 和 footer 用 `grid-column: 1 / 4` 跨整行，没有写 grid-row
- 五个区域不同背景色，均带 1px 黑边框

**导师验收：评分 9.5 分，判定：通过**

逐项评分：

- **概念理解 4/4**：`display: grid`、`grid-template-columns/rows`、`fr`、`grid-column`、`gap` 全部用对，注释是理解后的话（"从左至右依次是200px，自适应，200px"）。
- **代码正确性 3/3**：布局能跑通。**亮点**：header/footer 跨行没写 `grid-row`，靠 Grid 自动放置（auto-placement）自然落在第 1 行和第 3 行——sparse 模式下 footer 发现第 2 行放不下 3 列宽的格子，自动换到下一行，这个行为理解是对的。
- **边界处理 1.5/2**：见扣分项。
- **表达清晰度 1/1**：注释简洁、自己的话。

扣分项：

1. **`body` 默认 margin 未重置，扣 0.5 分（边界处理）**。`height: 100vh` + body 自带 8px 上下边距，实际总高是 `100vh + 16px`，页面底部会出现滚动条、四周有白边。加一行 `margin: 0` 即可。
2. （提示不扣分）`width: 100%` 对 body 是冗余声明——块级元素默认就是满宽。写声明之前先问一句"不写会怎样"。

做对的关键点：

- `grid-column: 1 / 4` 用网格线编号（不是列数）跨三列，概念准确；更简洁的写法是 `1 / -1`（负索引从末尾数）
- `1fr` 用在中间列自适应，没写成固定像素，掌握了 fr 的精髓
- 布局结构完全符合圣杯要求：200px + 1fr + 200px / 60px + 1fr + 60px

留了一道思考题（不用改代码）：把 header/footer 的 `grid-column: 1 / 4` 换成 `1 / -1`，想想为什么更健壮（列数从 3 改成 4 时，`1 / 4` 就不再跨整行了）。
