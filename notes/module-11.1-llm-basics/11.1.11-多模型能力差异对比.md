# 11.1.11 多模型能力差异对比

## 一句话说清楚
<!-- 用一句白话解释：不同 LLM 模型的差异体现在哪些方面？为什么要做模型选型？ -->
推理能力，编程能力，语言支持，成本；
模型选型是为了按照场景需求，选择更加适合的模型，来发挥模型的能力，并且控制好成本；

### 要点2：模型选型的决策逻辑
<!-- 这里写：在不同场景下（中文问答、复杂推理、成本敏感、数据安全）应该选哪个模型？给出具体例子 -->
  - 中文问答场景 → 选 DeepSeek（中文好且便宜）
  - 复杂推理场景 → 选 GPT-4（推理最强）
  - 数据安全场景 → 选 Llama 自部署（数据不出网）
  - 成本敏感场景 → 选 GPT-3.5（最便宜）
