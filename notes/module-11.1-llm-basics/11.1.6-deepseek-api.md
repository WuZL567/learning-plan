## 核心要点一：代码结构
（写清楚：DeepSeek API 调用的核心代码结构是什么？client 怎么初始化？create 方法的必填参数有哪些？）
client初始化：
from openai import OpenAI

client = OpenAI(
    api_key="你的API Key",  # 必填
    base_url="https://api.deepseek.com"  # 必填，指向DeepSeek的服务器
)

messages的role取值：
- system：系统提示词，设定AI的角色和行为规则（放最前面，只有1条）
- user：用户说的话
- assistant：AI的回复
- 顺序要求：system → user → assistant → user → assistant...（必须user和assistant交替）

多轮对话示例：
messages = [
    {"role": "system", "content": "你是一个前端专家"},
    {"role": "user", "content": "Vue3响应式原理是什么？"},
    {"role": "assistant", "content": "Vue3用Proxy代理对象..."},
    {"role": "user", "content": "和Vue2的Object.defineProperty有什么区别？"}
]

create方法的必填参数：
- model：模型名称（必填）
- messages：对话数组（必填）
- max_tokens、temperature是选填，不是必填
