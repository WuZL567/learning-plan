## 扣分项

### 扣分项 1：Token 机制理解不完整（-1.5 分）

**学生首次回答**："6 个 Token，你：1个，好：1个，世：1个，界：1个，Hello：1个，World：1个"

**问题**：理解为"一个字 = 1 个 Token"，这是错误的。

**正确答案**：
- 输入："你好世界" → 可能切分为 `["你好", "世界"]`（2 个 Token）或 `["你", "好", "世", "界"]`（4 个 Token），取决于模型的 Tokenizer
- 输出："Hello World" → 可能切分为 `["Hello", " World"]`（2 个 Token）
- 总共：输入 2-4 个 + 输出 2 个 = 4-6 个 Token

**关键点**：Token 不是"一个字 = 1 个 Token"，而是 Tokenizer 根据词表切分的。中文常见词（如"你好"）可能是 1 个 Token，生僻字可能是 2-3 个 Token。

**改进后**：学生补充了"Token 不是'一个字 = 1 个 Token'，而是 Tokenizer 根据词表切分的，常见词可能是 1 个 Token，生僻字可能是 2-3 个 Token"。

---

### 扣分项 2：上下文窗口对比理解不到位（-0.5 分）

**追问**：上下文窗口和 Vue 组件的 `props` 有什么本质区别？

**学生回答**："上下文窗口的大小有限制，超出限制的内容会被遗忘，而 props 有个数限制，超出的则报错"

**问题**："props 有个数限制，超出则报错"不准确。

**正确答案**：
- 上下文窗口：有固定容量（如 8k Token），超出后自动截断或遗忘前面的内容，不会报错
- Vue props：没有"个数限制"，可以传无限多个 props。真正的限制是内存，但不会主动"遗忘"

**本质区别**：上下文窗口是"滑动窗口"（只记住最近的内容），props 是"全量传递"（传多少就有多少）。

## 补充知识点

### 特殊符号、Emoji 占多少 Token？

- 常见标点符号（`,` `.` `!` `?`）通常是 1 个 Token
- Emoji 通常是 2-4 个 Token（因为 Emoji 是 Unicode 编码，占用多个字节）
- 代码中的特殊符号（`{}` `[]` `()`）通常是 1 个 Token

### Temperature 和 top_p 的区别？

- **Temperature**：控制概率分布的"平滑度"，0 表示只选概率最高的词，1 表示按原始概率分布随机选
- **top_p**（nucleus sampling）：只从累计概率前 p% 的词中选，比如 top_p=0.9 表示只考虑概率加起来占 90% 的候选词
- **区别**：Temperature 影响"随机性"，top_p 影响"候选范围"。一般两者配合使用，比如 Temperature=0.7 + top_p=0.9
