# 11.1.12 Token 计费与成本控制

## 一句话说清楚
<!-- 用一句白话解释：LLM 的计费方式是什么？输入和输出 token 价格有什么差异？ -->
Tokens数量，输入输出Tokens不相等，一般来说，输出Tokens更贵，贵的倍数由各自的大模型官方决定；

## 两个核心要点

### 要点1：Token 计费方式
<!-- 这里写：输入 token 和输出 token 分别怎么计费？不同模型的价格差异（举例 DeepSeek 和 GPT-4）？ -->
DeepSeek 输入 1 元/百万 tokens、输出 2 元/百万 tokens；GPT-4 输入 30 元/百万 tokens、输出 60 元/百万tokens，输出是输入的 2-3 倍

### 要点2：成本优化策略
<!-- 这里写：至少 3 个成本优化策略（限制 max_tokens、优化 prompt、缓存、用便宜模型等），每个策略举一个具体例子 -->
1、设置max_tokens，设置输出Token的长度； 防止LLM输出超长文本；
2、优化用户输入prompt，节省Tokens； 缩减用户输入Token；
3、使用缓存命中； 命中缓存的Tokens更加便宜；

## 不确定的部分
<!-- 诚实写出你没完全搞懂的点，比如：输出 token 为什么比输入贵？成本优化策略在实际项目中怎么平衡体验和成本？ -->
1、输出Token是你需要获取的内容，肯定是要更贵的；
2、按照实际使用场景+成本预算范围来决定，是要更好的体验还是要更低的成本；
