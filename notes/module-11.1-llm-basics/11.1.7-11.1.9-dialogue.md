**导师回答学生的三个问题**：

**Q1：通义千问的 result_format 参数除了 message 还有什么其他的值？**
- `"message"`：返回结构化消息格式（推荐，和 OpenAI 兼容）
- `"text"`：直接返回纯文本内容

**Q2：Claude 的 system 参数和 messages 里的 system 角色有什么本质区别？**
- Claude 认为 system 是"AI 的配置"，不是"对话内容"，所以单独拎出来
- 类比：system 是组件的 props，messages 是组件的 state

**Q3：如果要统一封装增加流式输出，该怎么修改？**
- 基类增加 `chat_stream` 方法
- 每个子类实现流式逻辑，返回生成器（generator）
- 前端用 SSE 或 WebSocket 接收
