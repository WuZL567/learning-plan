# 1.5 隐式类型转换规则

## 一、一句话说清楚

（这里用一句你自己的白话解释什么叫"隐式类型转换"。不要抄文档，用你理解的话写。）
在进行+，==等操作时，会对值的类型进行转换后再进行运算操作。
+符号时：有字符串时转字符串拼接，没有字符串时转成数字相加；
==规则：类型相同则===，null只和undefined相等，字符串vs数字转数字，有布尔值转数字，对象vs非对象，将对象拆分，先执行valueOf获取值，返回自身时再执行toString获取值，最后重复之前的规则，Date对象除外，先执行toString函数再执行valueOf函数；
非+符号和非==时：统统转成数字处理；

`+` 运算符的规则：
1. 有字符串时，转成字符串进行拼接；
2. 没有字符串时，转成数字进行相加；
`==` 宽松相等的规则：
1. 类型相同时，使用===比较；
2. null只和undefined相等；
3. 字符串vs数字，将字符串转成数字进行比较；
4. 有布尔值，转成数字进行比较；
5. 对象vs非对象，将对象拆分，执行valueOf获取值，如果返回自身，则再执行toString获取值，Date对象则先执行toString；[].toString返回''，{}则返回'[object Object]'；
非 `+` 和 非 `==` 的规则：
1. 统统转成数字进行操作；

ToNumber:
'' => 0;
'1' => 1;
true => 1;
false => 0;
undefined => NaN
null => 0
[] => 0

ToString:
true => 'true'
false => 'false'
0 => '0'
[] => ''
NaN => 'NaN'

ToBoolean:
只有 false，0，''，null，undefined，NaN 是 falsy，其它的（[],{},'0'）都是 truthy。
