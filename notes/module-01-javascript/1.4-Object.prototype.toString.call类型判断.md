# 1.4 Object.prototype.toString.call() 类型判断

## 第一部分：一句话说清楚

用自己的话，一句白话解释 Object.prototype.toString.call() 是干嘛的。

用来读取JS底层的内部类型标签，来判断参数的精准类型是什么。

## 第二部分：核心原理

用类比或对比表讲清楚它的核心原理。至少回答这三层：

1. 为什么不能直接用 `值.toString()`？哪些类型会出问题？
因为内置类型的toString函数基本都被改重写了，用来返回字符串，比如[123].toString()会返回字符串"123"，像Array，Number这些都会出问题；
null和undefined的toString函数调用会直接抛出错误，所以必须要用Object.prototype.toString；

2. `Object.prototype.toString` 和 `Array.prototype.toString` 有什么区别？
Array的toString函数被重写了，所以无法使用来判断类型，Array.prototype.toString会遍历元素，用逗号来拼接成字符串；

3. 它的返回值格式 `[object Xxx]` 中的 Xxx 是从哪里来的？ES6 之后有什么变化？
从内部类型标签读取来，[[class]]属性中；ES6之后有Symbol支持用toStringTag来修改自定义类型。
