## 一、我教了什么

1. 用 Vue 中 `data()` 为什么必须是函数引入闭包的必要性——每个组件实例需要独立的私有作用域。
2. 闭包的本质：函数定义时保留对定义位置词法环境的引用（`[[Environment]]`），调用时通过作用域链访问外层变量，且阻止垃圾回收。
3. 用"离开家乡但手机存着老家地址"类比闭包的内存模型，用"发动机与汽车"类比作用域链与闭包的关系。
4. 给了三个代码练习：私有计数器、once 函数、模块模式，覆盖闭包的三个典型应用场景。

## 二、他答了什么

核心理解：
- 闭包是函数记住定义时作用域，外部调用时通过作用域链访问内部变量
- 作用域链是"静态结构"（定义时确定），闭包是"动态应用"（运行时使用）
- 作用域链是闭包工作的底层机制，闭包是作用域链的具体实践

- 类型边界检查完备（typeof 检查、rest 参数 + spread 展开）
