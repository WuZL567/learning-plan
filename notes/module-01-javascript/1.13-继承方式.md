# 1.13 继承方式

## 一、一句话说清楚

> （提示：用一句白话解释 JS 继承到底在干什么，为什么需要它。）

你的答案：
让一个对象或构造函数通过原型链向上查找，拿到另一个对象或构造函数的属性和方法；为了直接复用属性和方法而不是自己重写；

---

## 二、核心原理

> （提示：用五种继承方式的对比表讲清楚每种方案的做法、优点、缺点。特别注意：寄生组合继承为什么是最优方案？ES6 class 和寄生组合继承是什么关系？）

你的答案：
function Animal(name) {
    this.name = name;
    this.color = ["black", "red"];
}
Animal.prototype.eat = function() {
    console.log(`${this.name} eatting!`);
}

1、原型链继承
function Dog1() {};
Dog1.prototype = new Animal('小白');
缺点：所有的子实例都共享了父类中引用类型属性，只要有一个子实例修改，全部都会受影响；无法向父类构造函数传递参数；

2、构造函数继承
function Dog2(name) {
    Animal.call(this, name);
};
缺点：无法访问Animal原型链的函数，比如eat；

3、组合继承（原型链+构造函数）
function Dog3(name) {
    Animal.call(this, name);
}
Dog3.prototype = new Animal('小黑');
缺点：调用了2次构造函数，第一次new，第二次call；

4、寄生组合继承
function Dog4(name) {
    // 获取父类属性
    Animal.call(this, name);
}
// 获取父类共享方法
Dog4.prototype = Object.create(Animal.prototype);
// 手动指定constructor向自己，因为不指定时是向着父类Animal的
Dog4.prototype.constructor = Dog4;
优点：最好的实践方式；
缺点：需要手动指定constructor，不然指向父类Animal

5、class/extends
class Dog5 extends Animal {
    // extends
    // 1. Dog5.prototype = Object.create(Animal.prototype)   ← 原型方法继承
    // 2. Object.setPrototypeOf(Dog5, Animal)                ← 静态属性继承
    // 3. Dog5.prototype.constructor = Dog5                  ← constructor 修正
    constructor(name) {
        super(name); // 等价于 Animal.call(this, name)
    }
}
优点：和寄生组合继承原理一致，是语法糖，更方便，不需要手动指定constructor；

## 三、和原型链的关系

> （提示：继承和原型链是什么关系？为什么理解原型链是理解继承的前提？`__proto__` 和 `prototype` 在继承中分别扮演什么角色？）

你的答案：
原型链是继承的基础，想要理解对象或构造函数的原型链才可以知道继承对象和构造函数的属性和方法的来源路径；
prototype是父级放置共享函数和属性的对象；
而__proto__则是继承者指向父级prototype的标志；

## 四、我的理解中不确定的部分

> （提示：诚实写出你还不太确定的地方。比如：寄生组合继承中为什么要修正 constructor 指向？class extends 和寄生组合继承有哪些细微差别？super 关键字具体做了什么？）

你的答案：

第一层：白话复述

▎ 用30秒解释寄生组合继承到底做了什么？为什么它叫"寄生"+"组合"？分别对应哪两个动作？

 - 寄生组合继承，通过call调用父函数来获取父类属性，通过使用Object.create基于父类原型创建子类的原型对象获取父类的共享方法；
 - 寄生是指基于父类原型通过Object.create来创建一个空的对象来寄生，不像组合继承那样使用new来产生冗余的实例属性，组合是指组合继承的方式；

第二层：对比理解

▎ 寄生组合继承和 ES6 class extends 有哪些细微差别？除了语法层面，底层行为上有区别吗？super(name) 在 class 里具体做了什么？

 - super(name)具体实现：Animal.call(this, name);
 - extends具体实现：
    1. Dog5.prototype = Object.create(Animal.prototype)   ← 原型方法继承
    2. Object.setPrototypeOf(Dog5, Animal)                ← 静态属性继承
    3. Dog5.prototype.constructor = Dog5                  ← constructor 修正

第三层：场景应用                                                                                                     
▎ 你的项目中有一个 BaseComponent，里面有 this.loading、this.error 状态和 this.fetch() 方法。现在你要写 UserComponent 继承它。用寄生组合继承的方式写出正确的代码（注意：实例属性用 call，原型方法用 Object.create）。

function BaseComponent(loading, error) {
    this.loading = loading;
    this.error = error;
}
BaseComponent.prototype.fetch = function () {};

function UserComponent(loading, error) {
    BaseComponent.call(this, loading, error);
}

UserComponent.prototype = Object.create(BaseComponent.prototype);
UserComponent.prototype.constructor = UserComponent;
