# 对话记录：1.7 作用域与作用域链

日期：2026-08-10

## 一、教了什么

作用域决定了变量在哪里能被访问到，JS 有全局作用域、函数作用域、块级作用域三种。var 没有块级作用域，let/const 才有。词法作用域（静态作用域）是 JS 的底层规则——作用域链在代码编写时就确定了，和运行时调用位置无关。作用域链的查找规则是"就近匹配，找到就停"，不会一路走到全局。TDZ 是块级作用域的安全机制，let/const 声明前不可访问。词法环境存 let/const/函数声明，变量环境存 var，两者初始化规则不同。

## 二、答了什么

学生正确识别了三种作用域和 var/let/const 的作用域差异。词法作用域定义准确。首次提交时代码示例有误（bar 定义在全局却描述了经过 foo 的查找路径），经指出后修正为 bar 嵌套在 foo 内部。TDZ 理解从"值为 undefined"修正为"访问报 ReferenceError"，并补上了代码示例。词法环境与变量环境的区别用自己的话写出了核心差异。实时代码追踪题首次答错（outer/inner 题输出"全局"），暴露了"就近匹配、找到就停"规则未形成直觉，学生对此诚实记录了。
