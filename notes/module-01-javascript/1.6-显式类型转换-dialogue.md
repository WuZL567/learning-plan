# 对话记录：1.6 显式类型转换

**日期：** 2026-08-10

---

## 一、教了什么

1. 显式类型转换和隐式转换的本质区别：隐式是 JS 引擎猜测意图，显式是用户主动干预类型。
2. 四个核心转换函数：Number()（严格数学转换，整个字符串必须合法）、String()（调用 toString，null/undefined 特殊处理）、Boolean()（只有 6 个 falsy 值）、parseInt()/parseFloat()（从左到右尽力解析，遇非数字停止）。
3. Number() 和 parseInt() 的核心区别：空字符串 Number → 0 而 parseInt → NaN；Number("12a") → NaN 而 parseInt("12a") → 12。

学生对显式类型转换的核心理解是准确的：
