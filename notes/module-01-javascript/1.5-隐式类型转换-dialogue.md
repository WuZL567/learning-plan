## 一、我教了什么

隐式类型转换的三大场景按运算符分类记忆：+ 运算符（有字符串就拼接，没字符串就转数字相加）、== 宽松相等（5 步规则：同类型→null/undefined→字符串转数字→布尔转数字→拆对象）、非+和==的运算符（统统转数字）。给出了 ToNumber / ToString / ToBoolean 三张速查表，以及 falsy 值只有 6 个的硬记规则。特别强调了几个高频面试陷阱：null == 0 是 false、[] == ![] 是 true、{} 的 toString 结果是 "[object Object]" 不是 0。
