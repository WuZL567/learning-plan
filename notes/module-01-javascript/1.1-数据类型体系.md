# JavaScript 数据类型体系

## 一、一句话说清楚
（用你自己的话，一句白话解释 JS 数据类型体系）

js数据类型体系分为原始类型和引用类型，基础类型使用栈内存，存的是值，拷贝时拷贝值，引用类型使用堆内存，存的是对象本体，栈里面存引用地址，拷贝时拷贝地址；
基本类型包括：string、number、boolean、bigInt、null、undefined、symbol这七种；
引用类型包括：array、object、date、function、regexp、map、set等；

## 二、核心原理
（用类比、图解或对比表讲清楚原始类型和引用类型的区别，以及7种原始类型各自的特征）

基本类型存的是值，可以直接拷贝，不会对原数据影响；
引用类型存的是引用，需要深拷贝才不会对原数据影响，否则改动会动到原数据；

string是字符串，包括模板字符串，如：let a1 = "A1"; let a2 = 'A2'; let a3 = ``;
number是普通数字，包括整数和小数；
boolean是布尔类型，值为true或false；
bigInt是大的整数，使用n结尾表示，如：let bigNum = 123123123n；
null是赋值为空，typeof null === 'object'；
undefined是找不到，定义但未赋值，let a; 时，a 就是 undefined；
symbol是唯一字符串，表示唯一的，可以用在对象的key中，如；const idx = Symbol('idx')；
