# 对话记录：1.3 instanceof 操作符原理与手写实现

日期：2026-08-07

## 一、我教了什么

instanceof 的本质是判断一个对象的原型链上是否存在某个构造函数的 prototype 属性，而不是判断对象"是什么类型"。核心原理是沿着 `__proto__` 链逐级向上查找，找到返回 true，找到 null 返回 false。教学中重点区分了两个易混淆点：`Object.getPrototypeOf(obj)` 获取的是对象的 `__proto__`，而 `Constructor.prototype` 是构造函数上的 prototype 属性，instanceof 对比的是后者。还讲了 typeof、instanceof、Object.prototype.toString.call 三者的适用场景差异。

## 二、他答了什么

笔记中正确理解了原型链查找过程：arr instanceof Array 沿着 `arr.__proto__ → Array.prototype` 找到，arr instanceof Object 则继续向上到 `Object.prototype`。代码实现中正确处理了 null/原始值返回 false、right 非函数抛 TypeError 等边界情况。第四部分诚实写出了三个不确定点：原始值 instanceof Number 为 false 的原因、Object.create(null) 的原型链断裂、原型链动态修改对 instanceof 的影响。
