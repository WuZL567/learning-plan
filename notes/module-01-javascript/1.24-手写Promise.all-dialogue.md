# 对话记录：1.24 手写 Promise.all

日期：2026-08-17

## 教学过程

### 为什么需要它

写前端，"并行请求"场景太多了：首页要同时拉用户信息、商品列表、轮播图配置，三个接口一起发，全部拿到才渲染页面。这时候原生 `Promise.all` 是最常用的写法。

面试官会问一句："它内部是怎么实现的？" 学生刚手写过 Promise（1.23，10分），知道 then、resolve、reject 怎么流转了，Promise.all 就是在这个基础上加一层"集合管理"。生产代码里万一要处理特殊场景（比如超时控制），知道原理才能自己包一层。

### 一句话说清楚

`Promise.all` 收一个数组，等里面所有 promise 都成功，把结果按输入顺序打包成一个数组还给你；只要任何一个失败，立刻 reject 并带上失败原因。

### 核心原理

把它想成管理一个团队任务：

- **计数管理**：团队里 N 个人，发出去 N 个任务，需要一个计数器。每完成一个人就 `count++`，直到 `count === 总数`，说明全员到齐，交付结果。
- **按位填坑**：任务完成顺序是不确定的（有人快有人慢），但交付时顺序必须和排队顺序一致。所以给每个任务分配固定座位：第 i 个任务完成，就把结果填到 `result[i]`，而不是 `result.push`（push 会按完成顺序排，就乱了）。就像按学号收卷子，第 3 号同学先交卷，也得放在第 3 个格子里。
- **一票否决**：只要有一个人失败，整个团队任务就失败了，不用等其他人。用 `reject` 直接结束，并把失败原因传出去。
- **降维打击普通值**：输入数组里可能有非 promise 的普通值，它没有 then 方法。用 `Promise.resolve(item)` 包一层，或者干脆不 then 直接填进结果。
- **空数组边界**：0 个人也要交付——没人失败，所以立刻 resolve 一个空数组 `[]`。这是个高频考点，很多人写漏。

伪代码骨架：

```js
function promiseAll(iterable) {
  return new Promise((resolve, reject) => {
    const arr = Array.from(iterable)   // 兼容任意可迭代对象
    const results = new Array(arr.length)  // 固定长度座位
    let count = 0                        // 完成计数器

    if (arr.length === 0) { resolve([]); return }  // 空数组边界

    arr.forEach((item, i) => {
      Promise.resolve(item).then(
        value => { results[i] = value; count++; if (count === arr.length) resolve(results) },
        reject   // 任何一个失败，直接一票否决
      )
    })
  })
}
```

**和手写 Promise 的关系**：1.23 写的是"单个任务的执行器"，Promise.all 是"任务调度员"。调度员本身不用关心单任务内部怎么流转，它只负责挂 then、数人头、按座位放结果。

## 验收过程

### 第一轮提交（核心内容）

学生实现了：

```js
function promiseAll(iterable) {
  return new Promise((resolve, reject) => {
    const newArray = Array.from(iterable);
    const result = new Array(newArray.length);
    let len = 0;

    if (newArray.length === 0) {
      resolve([]);
      return;
    }

    newArray.forEach((item, index) => {
      Promise.resolve(item).then(
        (value) => {
          result[index] = value;
          len++;
          if (len === result.length) {
            resolve(result);
          }
        },
        (error) => reject(error),
      )
    });
  });
}
```

文件末尾带了三个自测用例：基本用例、空数组、reject 用例（第三个没有挂 .catch）。
