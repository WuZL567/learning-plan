# 1.12 原型与原型链

## 第一部分：一句话说清楚

> 📝 用一句白话解释，什么是原型？什么是原型链？让一个完全没学过 JS 的人也能听懂。

原型（prototype）是JS上放置共享函数和属性的库；原型链则是通过访问__proto__属性来查找共享函数或属性，从自身开始找，找不到则向父级继续查找，直到找到或者返回null（找不到）为止，这样的路径就是原型链；

## 第三部分：原型链继承和 class extends 的关系

> 📝 class extends 是 ES6 的语法糖，它底层还是原型链。请你用自己的话解释：
> - class extends 和直接操作 prototype 做继承，本质上有哪些相同点？
> - 有哪些不同点（提示：super 关键字、静态属性继承、instanceof 行为）？

 - 原理上基本一致，只是class extends则是用了一些语法糖操作来节省代码量；
 - 手动继承需要通过call来指定this指向父级，这样就继承了里面的属性，而class中使用super函数即可，传递父级的属性给子级；
 - 手动继承是使用Object.create依据父级的prototype来创建子级的prototype对象，而class则extends时就创建了并且将原型链__proto__指向了父级的prototype；
 - 手动继承不能自动继承父级的静态属性，而是需要手动使用Object.setPrototypeOf函数来处理，而class是自动继承的；
