## 我不确定的部分

（这里诚实写出你没完全搞懂的点，比如"git reset --soft/--mixed/--hard 的区别"、"git restore 和 git checkout 有什么区别"等）
1、不知道这些区别，帮我补一下课；

git checkout -- <file>: 丢弃工作区修改，从暂存区或仓库恢复（旧命令，不推荐使用）
git restore <file>: 丢弃工作区修改（新命令，推荐使用）
git restore --staged <file>: 取消暂存，等价于 git reset HEAD <file>

git reset --soft <commitId>: 只回退本地仓库，暂存区和工作区不变；
git reset --mixed <commitId>: 回退本地仓库和暂存区，工作区不变；
git reset --hard <commitId>: 三个区域都回退，危险操作，会丢失工作区修改；
