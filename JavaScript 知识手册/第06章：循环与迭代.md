# 第06章：循环与迭代

## 6.1 循环与迭代概念

**一句话解释：**
循环就是**让同一段代码重复执行多次**，直到满足某个条件为止。迭代是**逐个访问集合中的每个元素**。

**餐厅比喻：**
- **循环** = 厨师反复做同一道菜——只要订单上还有，就继续做
- **迭代** = 服务员逐桌去点菜——从第1桌走到第10桌，每桌都问一遍

~~~
循环 vs 迭代
│
├── 循环（Loop）
│   └── 重复执行一段代码，直到条件不满足
│   └── 厨师反复做同一道菜，直到订单清空
│
└── 迭代（Iteration）
    └── 按顺序逐个访问集合中的每个元素
    └── 服务员从第1桌走到第10桌，每桌都问一遍
~~~

## 6.2 for 循环

**一句话解释：**
`for` 循环是最常用的循环，包含**初始化、条件判断、更新**三个部分，精确控制循环次数。

**餐厅比喻：**
你数储物柜——"从第1个柜子开始（初始化），数到第10个为止（条件），每数一个往后走一个（更新）"。

~~~javascript
// ========== 基本 for 循环 ==========
//   初始化    条件      更新
for (let i = 0; i < 5; i++) {
  console.log(`第${i + 1}个储物柜`);
}
// 第1个储物柜
// 第2个储物柜
// 第3个储物柜
// 第4个储物柜
// 第5个储物柜

// ========== 遍历数组 ==========
const 菜单 = ["红烧肉", "麻婆豆腐", "糖醋里脊", "宫保鸡丁"];

for (let i = 0; i < 菜单.length; i++) {
  console.log(`${i + 1}. ${菜单[i]}`);
}
// 1. 红烧肉
// 2. 麻婆豆腐
// 3. 糖醋里脊
// 4. 宫保鸡丁

// ========== 倒序遍历 ==========
for (let i = 菜单.length - 1; i >= 0; i--) {
  console.log(`倒数第${菜单.length - i}道：${菜单[i]}`);
}
// 倒数第1道：宫保鸡丁
// 倒数第2道：糖醋里脊
// 倒数第3道：麻婆豆腐
// 倒数第4道：红烧肉

// ========== 步长不为1 ==========
for (let i = 0; i <= 100; i += 20) {
  console.log(`进度：${i}%`);
}
// 进度：0%
// 进度：20%
// 进度：40%
// 进度：60%
// 进度：80%
// 进度：100%

// ========== 嵌套 for 循环 ==========
for (let 楼层 = 1; 楼层 <= 3; 楼层++) {
  for (let 房间 = 1; 房间 <= 4; 房间++) {
    console.log(`${楼层}楼${房间}号房`);
  }
}
// 1楼1号房
// 1楼2号房
// ...（共12个房间）
~~~

## 6.3 while / do...while

### while

**一句话解释：**
只要条件为 `true`，就一直执行循环体。**先判断条件，再决定是否执行。**

**餐厅比喻：**
厨师看了一眼订单——"还有菜没做完？那就继续做"。**每做一道之前先看一眼**，没订单了就停。

~~~javascript
// ========== 基本 while ==========
let 订单数 = 5;

while (订单数 > 0) {
  console.log(`还有${订单数}个订单，继续做菜...`);
  订单数--;
}
console.log("所有订单完成了！休息！");

// 还有5个订单，继续做菜...
// 还有4个订单，继续做菜...
// 还有3个订单，继续做菜...
// 还有2个订单，继续做菜...
// 还有1个订单，继续做菜...
// 所有订单完成了！休息！

// ========== 注意：如果条件一直为 true，会变成死循环 ==========
// let 永远 = true;
// while (永远) {
//   console.log("停不下来...");
//   // 永远不会结束！浏览器会卡死！
// }

// ========== 实际用途：逐个处理直到清空 ==========
const 待处理 = ["订单A", "订单B", "订单C"];

while (待处理.length > 0) {
  const 当前订单 = 待处理.shift();  // 从头部取出一个
  console.log(`处理：${当前订单}`);
}
console.log("全部处理完毕");
// 处理：订单A
// 处理：订单B
// 处理：订单C
// 全部处理完毕
~~~

### do...while

**一句话解释：**
先执行一次循环体，再判断条件。**至少会执行一次。**

**餐厅比喻：**
厨师不看订单，**先做一道菜端出来**，然后问"还需要继续做吗？"——即使订单是空的，这道菜也已经做了。

~~~javascript
// ========== 基本 do...while ==========
let 订单数 = 3;

do {
  console.log(`做了一道菜，还剩${订单数 - 1}个订单`);
  订单数--;
} while (订单数 > 0);
console.log("完成！");

// 做了一道菜，还剩2个订单
// 做了一道菜，还剩1个订单
// 做了一道菜，还剩0个订单
// 完成！

// ========== do...while 至少执行一次 ==========
let 订单数2 = 0;

do {
  console.log("即使订单为0，这道菜也做了");  // ✅ 会执行一次
  订单数2--;
} while (订单数2 > 0);
// 输出：即使订单为0，这道菜也做了

// ========== while vs do...while 对比 ==========
let 条件 = false;

// while：先判断，条件为 false，一次都不执行
while (条件) {
  console.log("while: 不会执行");
}

// do...while：先执行，再判断，至少执行一次
do {
  console.log("do...while: 至少执行一次");  // ✅
} while (条件);
~~~

## 6.4 for...in（遍历对象的键）

**一句话解释：**
`for...in` 遍历对象的**可枚举属性名（键）**，通常用于遍历对象。

**餐厅比喻：**
你拿到一张账单，**逐个翻看上面写了哪些项目名**——桌号、客人数、菜品、总价……一条条看过去。

~~~javascript
// ========== 遍历对象 ==========
const 账单 = {
  桌号: 5,
  客人数: 4,
  菜品: "红烧肉、麻婆豆腐",
  总价: 93
};

for (const 项目名 in 账单) {
  console.log(`${项目名}：${账单[项目名]}`);
}
// 桌号：5
// 客人数：4
// 菜品：红烧肉、麻婆豆腐
// 总价：93

// ========== for...in 遍历数组（不推荐） ==========
const 菜单 = ["红烧肉", "麻婆豆腐", "糖醋里脊"];

for (const 索引 in 菜单) {
  console.log(`${索引}: ${菜单[索引]}`);
}
// 0: 红烧肉
// 1: 麻婆豆腐
// 2: 糖醋里脊

// 注意：for...in 遍历数组时，索引是字符串 "0"、"1"、"2"，不是数字
for (const 索引 in 菜单) {
  console.log(typeof 索引);  // "string"（不是 "number"）
}

// ========== for...in 会遍历原型链上的属性 ==========
function 餐厅(名字) {
  this.名字 = 名字;
}
餐厅.prototype.类型 = "餐饮";

const 老王饭馆 = new 餐厅("老王饭馆");

for (const 属性 in 老王饭馆) {
  console.log(属性);
}
// 名字    ← 自身属性
// 类型    ← 原型链上的属性也会被遍历！

// 如果只想遍历自身属性，加 hasOwnProperty 判断
for (const 属性 in 老王饭馆) {
  if (老王饭馆.hasOwnProperty(属性)) {
    console.log(属性);
  }
}
// 名字    ← 只输出自身属性
~~~

## 6.5 for...of（遍历可迭代对象的值）

**一句话解释：**
`for...of` 遍历**可迭代对象**的**值**——数组、字符串、Map、Set 等都可以用。

**餐厅比喻：**
服务员从第1桌走到最后一桌，**每桌只看桌上的菜品（值）**，不关心桌号（键）。

~~~javascript
// ========== 遍历数组（最常用） ==========
const 菜单 = ["红烧肉", "麻婆豆腐", "糖醋里脊"];

for (const 菜 of 菜单) {
  console.log(菜);
}
// 红烧肉
// 麻婆豆腐
// 糖醋里脊

// ========== 遍历字符串 ==========
for (const 字 of "红烧肉") {
  console.log(字);
}
// 红
// 烧
// 肉

// ========== 遍历 Map ==========
const 菜品价格 = new Map([
  ["红烧肉", 38],
  ["麻婆豆腐", 22],
  ["糖醋里脊", 45]
]);

for (const [菜名, 价格] of 菜品价格) {
  console.log(`${菜名}：${价格}元`);
}
// 红烧肉：38元
// 麻婆豆腐：22元
// 糖醋里脊：45元

// ========== 遍历 Set ==========
const 今日食材 = new Set(["猪肉", "豆腐", "辣椒", "花椒"]);

for (const 食材 of 今日食材) {
  console.log(`食材：${食材}`);
}
// 食材：猪肉
// 食材：豆腐
// 食材：辣椒
// 食材：花椒

// ========== 遍历 arguments（函数参数列表） ==========
function 上菜(...菜品们) {
  for (const 菜 of 菜品们) {
    console.log(`上菜：${菜}`);
  }
}
上菜("红烧肉", "麻婆豆腐", "糖醋里脊");
// 上菜：红烧肉
// 上菜：麻婆豆腐
// 上菜：糖醋里脊
~~~

## 6.6 for...in vs for...of 对比

| | for...in | for...of |
|---|---|---|
| 遍历什么 | 对象的**键**（属性名） | 可迭代对象的**值** |
| 适用对象 | 普通对象 {} | 数组、字符串、Map、Set、arguments 等 |
| 索引类型 | 字符串 `"0"`, `"1"` | 无（直接拿到值） |
| 原型链 | 会遍历原型链上的属性 | 不会 |
| 遍历数组 | 不推荐（索引是字符串，会遍历原型） | 推荐（直接拿到值） |

~~~javascript
const 菜单 = ["红烧肉", "麻婆豆腐", "糖醋里脊"];

// for...in：拿到的是索引（字符串）
for (const x in 菜单) {
  console.log(x, typeof x);
}
// "0" "string"
// "1" "string"
// "2" "string"

// for...of：拿到的是值
for (const x of 菜单) {
  console.log(x);
}
// 红烧肉
// 麻婆豆腐
// 糖醋里脊

// ========== 一句话记住 ==========
// for...in → 对象的键 → "这个账单上有哪些项目名？"
// for...of → 数组的值 → "这盘菜里有哪些食材？"
~~~

## 6.7 break / continue / 标签循环

### break

**一句话解释：**
立即**跳出当前循环**，不再继续执行剩余的迭代。

~~~javascript
// ========== 找到就停 ==========
const 菜单 = ["红烧肉", "麻婆豆腐", "糖醋里脊", "宫保鸡丁"];
const 目标 = "糖醋里脊";

for (let i = 0; i < 菜单.length; i++) {
  if (菜单[i] === 目标) {
    console.log(`找到了！${目标}在第${i + 1}位`);
    break;  // 找到了就不再继续找了
  }
}
// 找到了！糖醋里脊在第3位
~~~

### continue

**一句话解释：**
跳过当前这一次迭代，**直接进入下一次**。

~~~javascript
// ========== 跳过不要的 ==========
const 菜单 = ["红烧肉", "麻婆豆腐", "拍黄瓜", "糖醋里脊"];

for (const 菜 of 菜单) {
  if (菜 === "拍黄瓜") {
    console.log("跳过凉菜：拍黄瓜");
    continue;  // 跳过这次，继续下一个
  }
  console.log(`上菜：${菜}`);
}
// 上菜：红烧肉
// 上菜：麻婆豆腐
// 跳过凉菜：拍黄瓜
// 上菜：糖醋里脊
~~~

### 标签循环

**一句话解释：**
给循环起个名字，然后可以用 `break 标签名` 跳出指定的那一层循环。

~~~javascript
// ========== 跳出多层嵌套循环 ==========
外层: for (let 楼层 = 1; 楼层 <= 3; 楼层++) {
  内层: for (let 房间 = 1; 房间 <= 5; 房间++) {
    if (楼层 === 2 && 房间 === 3) {
      console.log(`在${楼层}楼${房间}号房找到目标，停止搜索！`);
      break 外层;  // 直接跳出外层循环
    }
  }
}
// 在2楼3号房找到目标，停止搜索！

// ========== 如果不用标签，只能跳出内层 ==========
for (let 楼层 = 1; 楼层 <= 3; 楼层++) {
  let 找到 = false;
  for (let 房间 = 1; 房间 <= 5; 房间++) {
    if (楼层 === 2 && 房间 === 3) {
      找到 = true;
      break;  // 只跳出内层
    }
  }
  if (找到) break;  // 还得再判断一次才能跳出外层
}
~~~

## 6.8 数组方法式遍历

### forEach

**一句话解释：**
对数组的每个元素执行一次回调函数，**没有返回值**。

~~~javascript
const 菜单 = [
  { 名字: "红烧肉", 价格: 38 },
  { 名字: "麻婆豆腐", 价格: 22 },
  { 名字: "糖醋里脊", 价格: 45 }
];

菜单.forEach((菜品, 索引) => {
  console.log(`${索引 + 1}. ${菜品.名字} - ${菜品.价格}元`);
});
// 1. 红烧肉 - 38元
// 2. 麻婆豆腐 - 22元
// 3. 糖醋里脊 - 45元
~~~

### map

**一句话解释：**
对数组的每个元素执行回调函数，**返回一个新数组**（每个元素是回调的返回值）。

~~~javascript
const 菜单 = [
  { 名字: "红烧肉", 价格: 38 },
  { 名字: "麻婆豆腐", 价格: 22 },
  { 名字: "糖醋里脊", 价格: 45 }
];

const 菜名们 = 菜单.map(菜 => 菜.名字);
console.log(菜名们);  // ["红烧肉", "麻婆豆腐", "糖醋里脊"]

const 带编号 = 菜单.map((菜, i) => `${i + 1}. ${菜.名字}(${菜.价格}元)`);
console.log(带编号);
// ["1. 红烧肉(38元)", "2. 麻婆豆腐(22元)", "3. 糖醋里脊(45元)"]
~~~

### filter

**一句话解释：**
过滤数组，只保留**满足条件**的元素，返回新数组。

~~~javascript
const 菜单 = [
  { 名字: "红烧肉", 价格: 38, 类型: "热菜" },
  { 名字: "麻婆豆腐", 价格: 22, 类型: "热菜" },
  { 名字: "拍黄瓜", 价格: 12, 类型: "凉菜" },
  { 名字: "糖醋里脊", 价格: 45, 类型: "热菜" }
];

const 热菜 = 菜单.filter(菜 => 菜.类型 === "热菜");
console.log(热菜);
// [{ 名字: "红烧肉", ... }, { 名字: "麻婆豆腐", ... }, { 名字: "糖醋里脊", ... }]

const 贵菜 = 菜单.filter(菜 => 菜.价格 > 30);
console.log(贵菜);
// [{ 名字: "红烧肉", ... }, { 名字: "糖醋里脊", ... }]
~~~

### reduce

**一句话解释：**
把数组"浓缩"成**一个值**——累加、分组、拼接都可以。

~~~javascript
const 菜单 = [
  { 名字: "红烧肉", 价格: 38 },
  { 名字: "麻婆豆腐", 价格: 22 },
  { 名字: "糖醋里脊", 价格: 45 }
];

// ========== 累加：求总价 ==========
const 总价 = 菜单.reduce((累加, 菜) => 累加 + 菜.价格, 0);
console.log(总价);  // 105

// ========== 分组：按类型分组 ==========
const 菜单2 = [
  { 名字: "红烧肉", 类型: "热菜" },
  { 名字: "拍黄瓜", 类型: "凉菜" },
  { 名字: "麻婆豆腐", 类型: "热菜" }
];

const 按类型分组 = 菜单2.reduce((结果, 菜) => {
  if (!结果[菜.类型]) 结果[菜.类型] = [];
  结果[菜.类型].push(菜);
  return 结果;
}, {});
console.log(按类型分组);
// { 热菜: [{...}, {...}], 凉菜: [{...}] }
~~~

### find / findIndex

**一句话解释：**
`find` 找第一个满足条件的**元素**，`findIndex` 找第一个满足条件的**索引**。

~~~javascript
const 菜单 = [
  { 名字: "红烧肉", 价格: 38 },
  { 名字: "麻婆豆腐", 价格: 22 },
  { 名字: "糖醋里脊", 价格: 45 }
];

const 找到的 = 菜单.find(菜 => 菜.价格 > 40);
console.log(找到的);  // { 名字: "糖醋里脊", 价格: 45 }

const 索引 = 菜单.findIndex(菜 => 菜.名字 === "麻婆豆腐");
console.log(索引);    // 1

// 找不到返回 -1
const 没找到 = 菜单.findIndex(菜 => 菜.名字 === "龙虾");
console.log(没找到);  // -1
~~~

### some / every

**一句话解释：**
`some` 只要有**一个**满足条件就返回 `true`，`every` 要**全部**满足才返回 `true`。

~~~javascript
const 价格们 = [38, 22, 45, 12, 32];

// some：有没有超过40的？
console.log(价格们.some(x => x > 40));   // true（糖醋里脊45）

// some：有没有超过100的？
console.log(价格们.some(x => x > 100));  // false

// every：是不是全部大于0？
console.log(价格们.every(x => x > 0));   // true

// every：是不是全部大于20？
console.log(价格们.every(x => x > 20));  // false（拍黄瓜12不满足）
~~~

## 第06章 总结

| 术语 | 一句话解释 | 餐厅比喻关键词 |
|---|---|---|
| for 循环 | 初始化+条件+更新，精确控制次数 | 数储物柜，从第1个到第10个 |
| while | 条件为真就一直执行，先判断 | 有订单就继续做菜 |
| do...while | 至少执行一次，再判断 | 先做一道，再问还要不要 |
| for...in | 遍历对象的键 | 翻看账单上有哪些项目名 |
| for...of | 遍历可迭代对象的值 | 逐桌看桌上的菜品 |
| for...in vs for...of | 键 vs 值 | 项目名 vs 菜品本身 |
| break | 立即跳出循环 | 找到了就停 |
| continue | 跳过本次，进入下一次 | 跳过凉菜，继续上热菜 |
| 标签循环 | 给循环起名，精确跳出指定层 | 从三楼撤！ |
| forEach | 遍历数组，无返回值 | 逐桌通知，但不收集信息 |
| map | 遍历数组，返回新数组 | 逐桌点菜，记下菜名列表 |
| filter | 过滤，只留满足条件的 | 只留下热菜 |
| reduce | 把数组浓缩成一个值 | 所有菜品价格加在一起 |
| find | 找第一个满足条件的元素 | 找第一道超过40元的菜 |
| findIndex | 找第一个满足条件的索引 | 麻婆豆腐在第几位 |
| some | 有一个满足就 true | 有没有超过40元的菜？ |
| every | 全部满足才 true | 是不是每道菜都大于20元？ |
