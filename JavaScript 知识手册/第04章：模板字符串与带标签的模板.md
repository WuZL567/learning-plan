# 第04章：模板字符串与带标签的模板

## 4.1 模板字符串（反引号基础）

**一句话解释：**
用反引号 `` ` `` 包裹的字符串，可以**嵌入变量**、**写表达式**、**直接换行**，比单引号和双引号方便很多。

**餐厅比喻：**
普通字符串就像手写菜单——每个字都得一笔一画写，改个价格还得涂掉重写。模板字符串就像**电子菜单模板**——价格、菜名都是变量，你填什么它就显示什么，还能自动排版换行。

~~~javascript
const 菜名 = "红烧肉";
const 价格 = 38;

// ========== 传统方式（拼接） ==========
const 描述1 = "今日推荐：" + 菜名 + "，仅需" + 价格 + "元！";
console.log(描述1);  // 今日推荐：红烧肉，仅需38元！

// ========== 模板字符串（${} 嵌入变量） ==========
const 描述2 = `今日推荐：${菜名}，仅需${价格}元！`;
console.log(描述2);  // 今日推荐：红烧肉，仅需38元！

// ========== ${} 里可以写表达式 ==========
const 描述3 = `${菜名}打8折后只要${价格 * 0.8}元，立省${价格 * 0.2}元！`;
console.log(描述3);  // 红烧肉打8折后只要30.4元，立省7.6元！

// ========== 可以调用函数 ==========
function 折扣价(原价, 折数) {
  return (原价 * 折数).toFixed(1);
}
const 描述4 = `${菜名}特价：${折扣价(价格, 0.8)}元`;
console.log(描述4);  // 红烧肉特价：30.4元

// ========== 直接换行（不需要 \n） ==========
const 菜单展示 = `
  ╔══════════════════╗
  ║   今日推荐菜单    ║
  ╠══════════════════╣
  ║ ${菜名}    ${价格}元 ║
  ║ 麻婆豆腐    22元 ║
  ║ 糖醋里脊    45元 ║
  ╚══════════════════╝
`;
console.log(菜单展示);

// ========== 嵌套模板字符串 ==========
const 分类 = "热菜";
const 菜品列表 = ["红烧肉", "麻婆豆腐", "糖醋里脊"];
const 嵌套模板 = `${分类}有${菜品列表.length}道：${菜品列表.map(菜 => `【${菜}】`).join("、")}`;
console.log(嵌套模板);  // 热菜有3道：【红烧肉】、【麻婆豆腐】、【糖醋里脊】

// ========== 嵌入 HTML（前端常用） ==========
const 用户名 = "小李";
const 订单数 = 3;
const HTML = `
  <div class="欢迎卡片">
    <h2>欢迎回来，${用户名}！</h2>
    <p>您有 ${订单数} 个待处理订单</p>
  </div>
`;
~~~

## 4.2 带标签的模板（Tagged Templates）

**一句话解释：**
在模板字符串**前面**加一个**标签函数**，可以拦截和自定义模板字符串的处理过程，实现格式化输出、安全性过滤、多语言翻译等功能。

**餐厅比喻：**
想象你在餐厅写菜单，正常方式就是直接把内容写上去，写什么就是什么。而带标签的模板，相当于你请了一个**"加工员"**坐在旁边，你写什么他都会**先过一遍手**再呈上去——你要显示 38 元，他说"我给你加个 ¥ 符号，变成 ¥38"；你要显示用户输入的内容，他说"我先检查一下有没有危险内容再放进去"。

### 基本语法

~~~javascript
// 不带标签的普通模板字符串
const 结果1 = `价格：${价格}元`;
console.log(结果1);  // 价格：38元

// 带标签的模板字符串：在模板字符串前面加一个函数名
const 结果2 = 格式化`价格：${价格}元`;
//           ↑↑↑↑↑↑
//           标签函数名（可以是任意函数名）
console.log(结果2);  // 价格：¥38.00元
~~~

### 标签函数的参数结构

~~~javascript
// 标签函数接收两类参数：
// 1. strings：所有静态文字片段（数组）
// 2. ...values：所有 ${} 表达式的值（剩余参数）

function 格式化(strings, ...values) {
  console.log("静态文字：", strings);
  console.log("变量值：", values);

  // 拼接结果：把静态文字和格式化后的变量值交替拼起来
  let 结果 = "";
  strings.forEach((文字, i) => {
    结果 += 文字;
    if (i < values.length) {
      // 对变量值做格式化处理
      结果 += typeof values[i] === "number"
        ? `¥${values[i].toFixed(2)}`
        : values[i];
    }
  });
  return 结果;
}

const 价格 = 38;
const 菜名 = "红烧肉";
const 输出 = 格式化`菜名：${菜名}，价格：${价格}元`;
console.log(输出);
// 静态文字：["菜名：", "，价格：", "元"]
// 变量值：["红烧肉", 38]
// 输出："菜名：红烧肉，价格：¥38.00元"
~~~

### raw 属性——获取原始字符串

~~~javascript
function 获取原始(strings, ...values) {
  // strings.raw 可以获取未经转义处理的原始字符串
  console.log("普通：", strings[0]);
  console.log("原始：", strings.raw[0]);
}

获取原始`第一行\n第二行`;
// 普通： 第一行
//         第二行  （\n 被处理成了真正的换行）

// 原始： 第一行\n第二行  （\n 保持原样，没有被转义）

// 内置的 String.raw 就是利用这个特性
const 原始文本 = String.raw`换行符\n不会生效，制表符\t也不会`;
console.log(原始文本);  // 换行符\n不会生效，制表符\t也不会
~~~

### 实际应用场景

#### 场景1：格式化输出（自动添加单位）

~~~javascript
function 格式化菜单(strings, ...values) {
  return strings.reduce((结果, 字符串, i) => {
    let 值 = values[i] !== undefined ? values[i] : "";

    // 数字自动加 ¥ 和两位小数
    if (typeof 值 === "number") {
      值 = `¥${值.toFixed(2)}`;
    }

    return 结果 + 字符串 + 值;
  }, "");
}

const 菜品 = [
  { 名字: "红烧肉", 价格: 38 },
  { 名字: "麻婆豆腐", 价格: 22 },
  { 名字: "糖醋里脊", 价格: 45 }
];

菜品.forEach(菜 => {
  const 描述 = 格式化菜单`${菜.名字}：${菜.价格}元`;
  console.log(描述);
});
// 红烧肉：¥38.00元
// 麻婆豆腐：¥22.00元
// 糖醋里脊：¥45.00元
~~~

#### 场景2：防 XSS 攻击（转义用户输入）

~~~javascript
function 安全HTML(strings, ...values) {
  return strings.reduce((结果, 字符串, i) => {
    let 值 = values[i] !== undefined ? values[i] : "";

    // 转义 HTML 特殊字符
    if (typeof 值 === "string") {
      值 = 值
        .replace(/&/g, "&amp;")
        .replace(/</g, "&lt;")
        .replace(/>/g, "&gt;")
        .replace(/"/g, "&quot;")
        .replace(/'/g, "&#39;");
    }

    return 结果 + 字符串 + 值;
  }, "");
}

// 危险的用户输入（包含恶意脚本）
const 用户输入 = '<script>alert("你的密码被偷了！")</script>';

// 不带标签：直接拼接 → 危险！
const 危险HTML = `<p>${用户输入}</p>`;
console.log(危险HTML);
// <p><script>alert("你的密码被偷了！")</script></p>  ← 恶意代码被执行！

// 带标签：自动转义 → 安全！
const 安全结果 = 安全HTML`<p>${用户输入}</p>`;
console.log(安全结果);
// <p>&lt;script&gt;alert("你的密码被偷了！")&lt;/script&gt;</p>  ← 被转义了，安全！
~~~

#### 场景3：SQL 注入防护

~~~javascript
function 安全SQL(strings, ...values) {
  return strings.reduce((SQL, 字符串, i) => {
    let 值 = values[i] !== undefined ? values[i] : "";

    // 基本的 SQL 转义
    if (typeof 值 === "string") {
      值 = `'${值.replace(/'/g, "''")}'`;
    }

    return SQL + 字符串 + 值;
  }, "");
}

const 用户名 = "admin' OR '1'='1";  // 恶意输入

const 查询 = 安全SQL`SELECT * FROM users WHERE name = ${用户名}`;
console.log(查询);
// SELECT * FROM users WHERE name = 'admin'' OR ''1''=''1'
// ↑ 危险的 OR 被转义了，不会被当作 SQL 逻辑执行
~~~

#### 场景4：国际化 / 多语言翻译

~~~javascript
const 语言包 = {
  "zh": { "价格": "价格", "元": "元", "特价": "特价" },
  "en": { "价格": "Price", "元": "", "特价": "Special" }
};

function 创建翻译器(语言) {
  const 词典 = 语言包[语言] || 语言包["zh"];

  return function(strings, ...values) {
    return strings.reduce((结果, 字符串, i) => {
      // 翻译静态文字中的关键词
      let 翻译后 = 字符串;
      for (const [原文, 译文] of Object.entries(词典)) {
        翻译后 = 翻译后.replace(new RegExp(原文, "g"), 译文);
      }
      return 结果 + 翻译后 + (values[i] !== undefined ? values[i] : "");
    }, "");
  };
}

const 中文 = 创建翻译器("zh");
const 英文 = 创建翻译器("en");

const 价格 = 38;

console.log(中文`特价：${价格}元`);  // 特价：38元
console.log(英文`特价：${价格}元`);  // Special：38Price
// 注：实际国际化方案会更复杂，这里演示带标签模板的原理
~~~

#### 场景5：模板编译（简易版）

~~~javascript
function 编译模板(strings, ...values) {
  // 将模板字符串编译成一个可复用的函数
  const 模板 = strings.reduce((结果, 字符串, i) => {
    return 结果 + 字符串 + (i < values.length ? `\${${i}}` : "");
  }, "");

  return function(数据) {
    let 输出 = 模板;
    values.forEach((键, i) => {
      输出 = 输出.replace(`\${${i}}`, 数据[键] !== undefined ? 数据[键] : "");
    });
    return 输出;
  };
}

// 编译一次，复用多次
const 模板函数 = 编译模板`${"名字"}点了${"菜品"}，共${"总价"}元`;

console.log(模板函数({ 名字: "小李", 菜品: "红烧肉", 总价: 58 }));
// 小李点了红烧肉，共58元

console.log(模板函数({ 名字: "老王", 菜品: "麻婆豆腐", 总价: 22 }));
// 老王点了麻婆豆腐，共22元
~~~

## 4.3 带标签的模板 vs 普通函数——对比

~~~javascript
// ========== 用普通函数实现同样的功能 ==========
function 安全HTML普通(字符串s, ...值s) {
  return 字符串s.reduce((结果, 字符串, i) => {
    let 值 = 值s[i] !== undefined ? 值s[i] : "";
    if (typeof 值 === "string") {
      值 = 值.replace(/</g, "&lt;").replace(/>/g, "&gt;");
    }
    return 结果 + 字符串 + 值;
  }, "");
}

// 用普通函数调用
const 结果1 = 安全HTML普通(["<p>", "</p>"], '<script>alert("XSS")</script>');
console.log(结果1);

// 用带标签的模板调用（更优雅）
const 结果2 = 安全HTML`<p>${'<script>alert("XSS")</script>'}</p>`;
console.log(结果2);
// 两种方式效果相同，但带标签的模板写法更直观
// 就像在写真正的 HTML 一样，只在变量处做处理
~~~

## 第04章 总结

| 术语 | 一句话解释 | 餐厅比喻关键词 |
|---|---|---|
| 模板字符串 | 反引号包裹，可嵌入变量和表达式 | 电子菜单模板，填什么显示什么 |
| `${}` | 在模板字符串中嵌入变量或表达式 | 填空格的位置 |
| 多行字符串 | 反引号内直接换行 | 自动排版的电子菜单 |
| 带标签的模板 | 模板字符串前加函数名，拦截处理过程 | 请了个加工员先过一遍手 |
| 标签函数 | 接收 strings 和 values，自定义处理逻辑 | 加工员的工作规则 |
| strings | 静态文字片段组成的数组 | 菜单上不变的文字部分 |
| values | `${}` 表达式的值组成的数组 | 菜单上需要填写的变量部分 |
| strings.raw | 未经转义处理的原始字符串 | 原始手写稿件，不做任何处理 |
| 防 XSS | 用标签函数自动转义用户输入的危险字符 | 加工员检查危险内容再放进去 |
| 防 SQL 注入 | 用标签函数自动转义 SQL 特殊字符 | 防止有人在备注里写恶意指令 |
| 格式化输出 | 用标签函数自动添加单位、格式化数字 | 自动加 ¥ 符号和小数点 |
| 国际化 | 用标签函数实现多语言翻译 | 同一条菜单翻译成各国版本 |
