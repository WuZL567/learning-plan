# 第07章：函数基础

## 7.1 函数声明 / 函数表达式 / 箭头函数

### 函数声明（Function Declaration）

**一句话解释：**
用 `function` 关键字直接声明一个函数，有名字、有函数体。函数声明会被**整体提升**。

**餐厅比喻：**
你把一道菜的完整做法写在菜单上，贴在墙上——**任何人都能直接点这道菜**（声明前也能调用）。

~~~javascript
// ========== 函数声明 ==========
function 做菜(菜名) {
  console.log(`正在做${菜名}...`);
  return `${菜名}做好了`;
}

const 结果 = 做菜("红烧肉");
console.log(结果);  // 红烧肉做好了

// ========== 函数声明会被整体提升 ==========
上菜();  // ✅ 可以在声明前调用

function 上菜() {
  console.log("菜来了！");
}
~~~

### 函数表达式（Function Expression）

**一句话解释：**
把一个匿名（或有名字）的函数赋值给一个变量。函数表达式**不会整体提升**。

**餐厅比喻：**
你把菜谱写在一张纸条上，塞进一个叫"今天特供"的信封里——**信封（变量）提前给你了，但纸条（函数体）还在原地没动**，你打开信封才能看到做法。

~~~javascript
// ========== 匿名函数表达式 ==========
const 做菜2 = function(菜名) {
  return `${菜名}做好了`;
};
console.log(做菜2("麻婆豆腐"));  // 麻婆豆腐做好了

// ========== 命名函数表达式（函数有自己的名字，但外面用不到） ==========
const 做菜3 = function 做菜内部名(菜名) {
  console.log(做菜内部名.name);  // "做菜内部名"（调试用）
  return `${菜名}做好了`;
};
console.log(做菜3("糖醋里脊"));  // 糖醋里脊做好了

// ========== 函数表达式不会整体提升 ==========
// 做菜4();  // ❌ TypeError: 做菜4 is not a function
var 做菜4 = function() {
  console.log("菜来了");
};
做菜4();  // ✅ 赋值之后才能调用
~~~

### 箭头函数（Arrow Function）

**一句话解释：**
用 `=>` 写的简短函数，**没有自己的 `this`**（继承外层的 `this`）。

**餐厅比喻：**
箭头函数就像一个**临时工**——干的活跟正式工一样简单，但它**没有自己的工位**（没有自己的 `this`），**不能当主管**（不能当构造函数），**没有工牌编号**（没有 `arguments`）。它借用隔壁正式工的工位干活。

~~~javascript
// ========== 基本写法 ==========
// 普通函数
const 做菜1 = function(菜名) {
  return `${菜名}做好了`;
};

// 箭头函数（完整写法）
const 做菜2 = (菜名) => {
  return `${菜名}做好了`;
};

// 箭头函数（只有一个参数时，括号可省略）
const 做菜3 = 菜名 => {
  return `${菜名}做好了`;
};

// 箭头函数（函数体只有一行时，可省略 {} 和 return）
const 做菜4 = 菜名 => `${菜名}做好了`;

console.log(做菜4("红烧肉"));  // 红烧肉做好了

// ========== 无参数时，括号不能省略 ==========
const 打招呼 = () => "欢迎光临";
console.log(打招呼());  // 欢迎光临

// ========== 多个参数时，必须加括号 ==========
const 计算总价 = (单价, 数量) => 单价 * 数量;
console.log(计算总价(38, 2));  // 76

// ========== 返回对象时，加括号防止 {} 被当成代码块 ==========
const 创建菜品 = (名字, 价格) => ({ 名字, 价格 });
console.log(创建菜品("红烧肉", 38));
// { 名字: "红烧肉", 价格: 38 }

// 不加括号会报错：
// const 创建菜品2 = (名字, 价格) => { 名字, 价格 };  // ❌ {} 被当成代码块了

// ========== 箭头函数没有自己的 this ==========
const 餐厅 = {
  名字: "老王饭馆",
  // 普通函数：this 指向调用它的对象（餐厅）
  报名1: function() {
    console.log(`欢迎来到${this.名字}`);  // ✅ this = 餐厅
  },
  // 箭头函数：this 继承外层（定义时的外层作用域）
  报名2: () => {
    console.log(`欢迎来到${this.名字}`);  // ❌ this ≠ 餐厅！
  }
};

餐厅.报名1();  // 欢迎来到老王饭馆
餐厅.报名2();  // 欢迎来到undefined（this 指向了外层，不是餐厅）

// ========== 箭头函数不能当构造函数 ==========
const 厨师 = (名字) => { this.名字 = 名字; };
// const 小王 = new 厨师("小王");  // ❌ TypeError: 厨师 is not a constructor

// ========== 箭头函数没有 arguments ==========
const 测试 = () => {
  // console.log(arguments);  // ❌ ReferenceError: arguments is not defined
};
// 需要用 ...rest 代替
const 测试2 = (...参数们) => {
  console.log(参数们);  // ✅ [1, 2, 3]
};
测试2(1, 2, 3);
~~~

### 三种函数写法对比

| | 函数声明 | 函数表达式 | 箭头函数 |
|---|---|---|---|
| 写法 | `function 做菜() {}` | `const 做菜 = function() {}` | `const 做菜 = () => {}` |
| 提升 | 整体提升 | 仅变量提升 | 仅变量提升 |
| 声明前调用 | ✅ 能 | ❌ 不能 | ❌ 不能 |
| 自己的 this | ✅ 有 | ✅ 有 | ❌ 没有（继承外层） |
| arguments | ✅ 有 | ✅ 有 | ❌ 没有 |
| 能当构造函数 | ✅ 能 | ✅ 能 | ❌ 不能 |
| 适合场景 | 通用 | 通用 | 回调函数、需要继承外层 this |

## 7.2 参数 / 实参 / 默认参数 / 剩余参数

### 形参和实参

~~~javascript
// 形参（Parameter）：函数定义时的"占位符"
// 实参（Argument）：函数调用时传入的"实际值"

function 做菜(菜名, 价格) {
  //       ↑形参  ↑形参
  console.log(`${菜名}，${价格}元`);
}

做菜("红烧肉", 38);
//  ↑实参   ↑实参
~~~

### 默认参数

~~~javascript
// ========== 基本默认参数 ==========
function 点菜(菜名, 数量 = 1, 备注 = "不要辣") {
  console.log(`${菜名} × ${数量}，备注：${备注}`);
}

点菜("红烧肉");            // 红烧肉 × 1，备注：不要辣
点菜("麻婆豆腐", 2);       // 麻婆豆腐 × 2，备注：不要辣
点菜("糖醋里脊", 3, "多醋"); // 糖醋里脊 × 3，备注：多醋

// ========== undefined 会触发默认值，null 不会 ==========
点菜("红烧肉", undefined, "微辣");  // 红烧肉 × 1，备注：微辣
点菜("红烧肉", null, "微辣");       // 红烧肉 × null，备注：微辣

// ========== 默认值可以是表达式 ==========
function 创建订单(桌号, 时间 = new Date().toLocaleString()) {
  console.log(`桌号${桌号}，时间：${时间}`);
}
创建订单(5);  // 桌号5，时间：2025/7/22 14:30:00

// ========== 后面的默认值可以引用前面的参数 ==========
function 做菜(食材, 调料 = `${食材}专用酱`) {
  console.log(`用${调料}做${食材}`);
}
做菜("红烧肉");  // 用红烧肉专用酱做红烧肉
~~~

### 剩余参数（Rest Parameters）

~~~javascript
// ========== 用 ... 收集剩余参数 ==========
function 上菜(主菜, ...配菜们) {
  console.log(`主菜：${主菜}`);
  console.log(`配菜：${配菜们.join("、")}`);
}

上菜("红烧肉", "米饭", "紫菜汤", "水果拼盘");
// 主菜：红烧肉
// 配菜：米饭、紫菜汤、水果拼盘

// ========== 剩余参数是真正的数组 ==========
function 统计(...所有价格) {
  console.log(Array.isArray(所有价格));  // true
  console.log(所有价格.length);          // 3
  const 总价 = 所有价格.reduce((a, b) => a + b, 0);
  console.log(`总价：${总价}`);
}
统计(38, 22, 45);  // 总价：105

// ========== arguments vs 剩余参数 ==========
function 旧写法() {
  // arguments 是类数组，不是真正的数组
  console.log(Array.isArray(arguments));  // false
  // 需要 Array.from(arguments) 或 [...arguments] 转成数组
}

function 新写法(...参数们) {
  // 剩余参数是真正的数组，可以直接用数组方法
  console.log(Array.isArray(参数们));  // true
  参数们.forEach(p => console.log(p));
}
~~~

## 7.3 返回值 return

**一句话解释：**
`return` 让函数**返回一个值**给调用者，并**立即结束**函数的执行。

~~~javascript
// ========== 基本返回 ==========
function 计算总价(单价, 数量) {
  return 单价 * 数量;  // 返回计算结果，函数结束
}

const 总价 = 计算总价(38, 2);
console.log(总价);  // 76

// ========== 没有 return 返回 undefined ==========
function 打招呼() {
  console.log("欢迎光临");
  // 没有 return
}
const 结果 = 打招呼();
console.log(结果);  // undefined

// ========== return 后面的代码不会执行 ==========
function 判断(利润) {
  if (利润 > 0) {
    return "盈利";  // 到这里函数就结束了
  }
  return "亏损";    // 利润 <= 0 才会执行到这里
}
console.log(判断(500));   // 盈利
console.log(判断(-200));  // 亏损

// ========== 返回多个值（用数组或对象） ==========
function 获取菜品信息() {
  return {
    名字: "红烧肉",
    价格: 38,
    评分: 4.8
  };
}

const { 名字, 价格, 评分 } = 获取菜品信息();
console.log(`${名字}，${价格}元，评分${评分}`);

// ========== 箭头函数简写返回 ==========
const 平方 = x => x * x;  // 单行自动返回
const 组装 = (名, 价) => ({ 名字: 名, 价格: 价 });  // 返回对象要加括号
~~~

## 7.4 arguments 对象

**一句话解释：**
`arguments` 是函数内部的一个**类数组对象**，包含了调用时传入的**所有实参**，不管形参定义了几个。

~~~javascript
// ========== arguments 包含所有实参 ==========
function 做菜() {
  console.log(arguments);        // [Arguments] { '0': '红烧肉', '1': '大份', '2': '微辣' }
  console.log(arguments.length); // 3
  console.log(arguments[0]);     // 红烧肉
  console.log(arguments[1]);     // 大份
}

做菜("红烧肉", "大份", "微辣");

// ========== arguments 是类数组，不是真正的数组 ==========
function 测试() {
  console.log(Array.isArray(arguments));  // false
  console.log(typeof arguments);          // "object"

  // 不能直接用数组方法
  // arguments.forEach(...);  // ❌ TypeError

  // 转成真正的数组
  const 参数数组 = Array.from(arguments);
  // 或
  const 参数数组2 = [...arguments];
  参数数组2.forEach(p => console.log(p));
}

// ========== 箭头函数没有 arguments ==========
const 箭头 = () => {
  // console.log(arguments);  // ❌ ReferenceError
};

// 用 ...rest 代替
const 箭头2 = (...参数们) => {
  console.log(参数们);  // ✅ 真正的数组
};

// ========== 严格模式下 arguments 有变化 ==========
function 严格测试(a) {
  "use strict";
  a = 99;
  console.log(arguments[0]);  // 1（严格模式下 arguments 不随形参改变）
}
严格测试(1);

function 非严格测试(a) {
  a = 99;
  console.log(arguments[0]);  // 99（非严格模式下 arguments 跟着形参变）
}
非严格测试(1);
~~~

## 7.5 函数声明的提升

**一句话解释：**
函数声明（`function xxx()`）会被**整体提升**到作用域顶部——声明和函数体都提升，所以可以在声明之前调用。

~~~javascript
// ========== 函数声明：整体提升 ==========
做菜();  // ✅ 输出：正在做菜...

function 做菜() {
  console.log("正在做菜...");
}

// ========== 函数表达式：只有变量声明提升 ==========
// 做菜2();  // ❌ TypeError: 做菜2 is not a function
var 做菜2 = function() {
  console.log("做菜2...");
};
做菜2();  // ✅ 赋值后才能用

// ========== const/let 的函数表达式：暂时性死区 ==========
// 做菜3();  // ❌ ReferenceError
const 做菜3 = function() {
  console.log("做菜3...");
};
做菜3();  // ✅
~~~

## 7.6 回调函数

**一句话解释：**
把函数**作为参数**传给另一个函数，让那个函数在合适的时候**回过头来调用**它。

**餐厅比喻：**
你跟服务员说："**菜好了叫我**"——你把"叫我"这个动作（回调函数）交给了厨房（另一个函数），厨房做好菜后**回过头来调用你的"叫我"动作**。

~~~javascript
// ========== 基本回调 ==========
function 做菜(菜名, 做好了通知) {
  console.log(`开始做${菜名}...`);
  // 模拟做完
  做好了通知(`${菜名}做好了！`);
}

做菜("红烧肉", function(消息) {
  console.log(`收到通知：${消息}`);
});
// 开始做红烧肉...
// 收到通知：红烧肉做好了！

// ========== 回调的实际例子：setTimeout ==========
setTimeout(function() {
  console.log("2秒后执行这个回调");
}, 2000);

// ========== 回调的实际例子：数组方法 ==========
const 菜单 = ["红烧肉", "麻婆豆腐", "糖醋里脊"];
菜单.forEach(function(菜, 索引) {
  console.log(`${索引 + 1}. ${菜}`);
});

// ========== 回调的实际例子：事件监听 ==========
// document.querySelector("button").addEventListener("click", function() {
//   console.log("按钮被点了（回调执行）");
// });
~~~

## 7.7 纯函数 vs 非纯函数

**一句话解释：**
- **纯函数**：相同的输入，永远得到相同的输出，不产生任何"副作用"
- **非纯函数**：除了返回值，还会修改外部状态或依赖外部变量

**餐厅比喻：**
- **纯厨师**：你给他同样的食材，他**永远做出一模一样的菜**，而且不会把厨房弄脏
- **非纯厨师**：他做菜时会偷吃一点（修改外部状态），或者有时候心情好做得好吃、心情差做得难吃（依赖外部变量）

~~~javascript
// ========== 纯函数 ==========
// 相同输入 → 相同输出，无副作用
function 计算总价(单价, 数量) {
  return 单价 * 数量;
}

console.log(计算总价(38, 2));  // 76
console.log(计算总价(38, 2));  // 76（永远一样）
console.log(计算总价(38, 2));  // 76（永远一样）

// ========== 非纯函数：依赖外部状态 ==========
let 税率 = 0.06;

function 含税价(价格) {
  return 价格 * (1 + 税率);  // 依赖外部的税率
}

console.log(含税价(100));  // 106

税率 = 0.1;  // 外部状态变了
console.log(含税价(100));  // 110（同样的输入，输出变了！）

// ========== 非纯函数：修改外部状态 ==========
let 订单列表 = [];

function 添加订单(订单) {
  订单列表.push(订单);  // 修改了外部的订单列表（副作用）
  return 订单列表.length;
}

console.log(添加订单("红烧肉"));  // 1
console.log(订单列表);  // ["红烧肉"]（被修改了）

// ========== 纯函数版本 ==========
function 添加订单2(原列表, 新订单) {
  return [...原列表, 新订单];  // 不修改原列表，返回新数组
}

const 新列表 = 添加订单2(["红烧肉"], "麻婆豆腐");
console.log(新列表);         // ["红烧肉", "麻婆豆腐"]
// 原来的 ["红烧肉"] 没被修改
~~~

## 7.8 IIFE（立即执行函数）

**一句话解释：**
定义完**立刻就执行**的函数，不需要手动调用。用 `(function(){})()` 包裹，形成一个独立的作用域。

**餐厅比喻：**
你写了一张临时任务卡，做完就扔——**写完立刻执行，执行完里面的变量就消失了**，不会影响外面的环境。

~~~javascript
// ========== 基本 IIFE ==========
(function() {
  console.log("我立刻执行了！");
})();
// 输出：我立刻执行了！

// ========== 带参数的 IIFE ==========
(function(菜名, 价格) {
  console.log(`${菜名}：${价格}元`);
})("红烧肉", 38);
// 输出：红烧肉：38元

// ========== 带返回值的 IIFE ==========
const 结果 = (function() {
  return "IIFE的返回值";
})();
console.log(结果);  // IIFE的返回值

// ========== IIFE 的核心作用：隔离作用域 ==========
(function() {
  const 秘方 = "酱油+醋+蒜";  // 外面访问不到
  console.log(秘方);
})();

// console.log(秘方);  // ❌ ReferenceError（IIFE 里的变量消失了）

// ========== 避免变量污染 ==========
(function() {
  var 临时变量 = "只在这个IIFE里用";
  console.log(临时变量);
})();

// console.log(临时变量);  // ❌ 污染不到全局

// ========== 箭头函数版 IIFE ==========
(() => {
  console.log("箭头函数版 IIFE");
})();

// ========== 带参数的箭头函数版 IIFE ==========
((甲, 乙) => {
  console.log(甲 + 乙);
})(3, 5);  // 8
~~~

## 7.9 预定义函数

**一句话解释：**
JS 内置的全局函数，不需要导入，任何地方都能直接调用。

### parseInt / parseFloat

~~~javascript
// ========== parseInt：从字符串提取整数 ==========
console.log(parseInt("38元"));        // 38（提取数字部分）
console.log(parseInt("12.99元"));     // 12（只取整数）
console.log(parseInt("abc"));         // NaN（完全没有数字）
console.log(parseInt("0xff", 16));    // 255（十六进制转十进制）
console.log(parseInt("1010", 2));     // 10（二进制转十进制）
console.log(parseInt("010"));         // 10（前导0被忽略）

// ========== parseFloat：从字符串提取浮点数 ==========
console.log(parseFloat("3.14元"));    // 3.14
console.log(parseFloat("12.99"));     // 12.99
console.log(parseFloat("1.5e3"));     // 1500（科学计数法）
~~~

### isNaN / isFinite

~~~javascript
// ========== isNaN：判断是否是 NaN ==========
console.log(isNaN(NaN));              // true
console.log(isNaN("abc"));            // true（"abc"转数字是NaN）
console.log(isNaN("123"));            // false（"123"能转成123）
console.log(isNaN(undefined));        // true
console.log(isNaN(null));             // false（null转成0）

// 推荐用 Number.isNaN（更严格）
console.log(Number.isNaN(NaN));       // true
console.log(Number.isNaN("abc"));     // false（不转换，直接判断）
console.log(Number.isNaN(undefined)); // false

// ========== isFinite：判断是否是有限数字 ==========
console.log(isFinite(42));            // true
console.log(isFinite(Infinity));      // false
console.log(isFinite(-Infinity));     // false
console.log(isFinite("123"));         // true（"123"转成123）
console.log(isFinite("abc"));         // false

// 推荐用 Number.isFinite（不转换字符串）
console.log(Number.isFinite(42));     // true
console.log(Number.isFinite("123"));  // false（字符串直接返回false）
~~~

### encodeURI / encodeURIComponent

~~~javascript
// ========== encodeURI：编码整个 URL（不编码特殊URL字符） ==========
const URL1 = "https://example.com/菜单?菜名=红烧肉&价格=38";
console.log(encodeURI(URL1));
// "https://example.com/%E8%8F%9C%E5%8D%95?%E8%8F%9C%E5%90%8D=%E7%BA%A2%E7%83%A7%E8%82%89&%E4%BB%B7%E6%A0%BC=38"

// ========== encodeURIComponent：编码 URL 参数值（更彻底） ==========
const 参数值 = "红烧肉&特价=是";
console.log(encodeURIComponent(参数值));
// "%E7%BA%A2%E7%83%A7%E8%82%89%26%E7%89%B9%E4%BB%B7%3D%E6%98%AF"

// 区别：encodeURI 不编码 : / ? # & = 等URL字符
//       encodeURIComponent 会编码这些字符

// ========== 解码 ==========
decodeURI(encodeURI(URL1));              // 还原
decodeURIComponent(encodeURIComponent(参数值));  // 还原

// ========== 实际用途：构建查询参数 ==========
function 构建URL(基础, 参数) {
  const 查询 = Object.entries(参数)
    .map(([键, 值]) => `${encodeURIComponent(键)}=${encodeURIComponent(值)}`)
    .join("&");
  return `${基础}?${查询}`;
}

console.log(构建URL("https://api.example.com/search", {
  菜名: "红烧肉",
  类型: "热菜",
  价格范围: "30-50"
}));
// "https://api.example.com/search?%E8%8F%9C%E5%90%8D=%E7%BA%A2%E7%83%A7%E8%82%89&..."
~~~

### eval

**一句话解释：**
把字符串当作 JS 代码来执行。**非常危险，几乎不应该使用。**

~~~javascript
// ========== 基本用法 ==========
eval('console.log("这行代码是从字符串执行的")');
// 输出：这行代码是从字符串执行的

eval('2 + 3');  // 5

// ========== 为什么危险 ==========
const 用户输入 = 'alert("你的密码被偷了！")';
// eval(用户输入);  // ❌ 会执行恶意代码！

// ========== eval 的作用域问题 ==========
function 测试() {
  eval("var 秘密变量 = 42");  // eval 里声明的变量会泄漏到外层作用域！
  console.log(秘密变量);  // 42
}
测试();
// console.log(秘密变量);  // 在严格模式下会报错

// ========== eval 的替代方案 ==========
// 1. JSON.parse 替代 eval 解析数据
const 数据 = '{"名字":"红烧肉","价格":38}';
const 对象 = JSON.parse(数据);  // ✅ 安全
// const 对象2 = eval('(' + 数据 + ')');  // ❌ 危险

// 2. new Function 替代动态执行代码
const 动态函数 = new Function("甲", "乙", "return 甲 + 乙");
console.log(动态函数(3, 5));  // 8
~~~

## 第07章 总结

| 术语 | 一句话解释 | 餐厅比喻关键词 |
|---|---|---|
| 函数声明 | function 直接声明，整体提升 | 菜谱完整贴在墙上 |
| 函数表达式 | 函数赋值给变量，仅变量提升 | 菜谱写在纸条塞进信封 |
| 箭头函数 | `=>` 简写，没有自己的 this | 临时工，没有自己的工位 |
| 默认参数 | 参数不传就用默认值 | 没说数量就默认1份 |
| 剩余参数 ...rest | 收集剩余参数为数组 | 除了主菜，其他全装一个盘子 |
| return | 返回值并结束函数 | 做好了端出来 |
| arguments | 函数内获取所有实参（类数组） | "你传了几个参数我都记着" |
| 回调函数 | 函数当参数传给另一个函数 | 菜好了叫我 |
| 纯函数 | 相同输入→相同输出，无副作用 | 纯厨师，永远做出一样的菜 |
| 非纯函数 | 依赖外部状态或产生副作用 | 偷吃的厨师，还会弄脏厨房 |
| IIFE | 定义后立刻执行，隔离作用域 | 临时任务卡，做完就扔 |
| parseInt | 从字符串提取整数 | 从"38元"里提取38 |
| parseFloat | 从字符串提取浮点数 | 从"3.14元"里提取3.14 |
| isNaN | 判断是否是NaN | 计算器出错了？ |
| isFinite | 判断是否是有限数字 | 数字是正常的吗？ |
| encodeURI | 编码整个URL | 把菜单翻译成快递能寄的格式 |
| encodeURIComponent | 编码URL参数值 | 把备注翻译成安全的格式 |
| eval | 把字符串当代码执行（危险） | 递纸条给厨师，他当场照做 |
