# 第08章：this 绑定规则与 call/apply/bind

## 8.1 this 是什么

**一句话解释：**
`this` 是函数内部的一个特殊变量，它指向**当前函数被调用时的"主人"**——谁调用了这个函数，`this` 就是谁。

**餐厅比喻：**
`this` 就像"**我们店**"这个说法——同样的厨师张师傅，在老王饭馆工作时说"我们店"指的是老王饭馆，被借调到老李饭馆后说"我们店"指的是老李饭馆。**"我们店"是谁，取决于张师傅此刻在哪干活**（谁调用了他）。

~~~javascript
// ========== this 的基本概念 ==========
const 老王饭馆 = {
  名字: "老王饭馆",
  报名() {
    console.log(`这里是${this.名字}`);  // this 指向调用它的对象
  }
};

const 老李饭馆 = {
  名字: "老李饭馆",
  报名: 老王饭馆.报名  // 同一个函数
};

老王饭馆.报名();  // 这里是老王饭馆（this = 老王饭馆）
老李饭馆.报名();  // 这里是老李饭馆（this = 老李饭馆）
// 同一个函数，因为调用者不同，this 指向不同
~~~

## 8.2 默认绑定（独立函数调用）

**一句话解释：**
函数被**直接调用**，没有被任何对象"拥有"时，`this` 指向全局对象（浏览器中是 `window`，严格模式下是 `undefined`）。

**餐厅比喻：**
张师傅今天没有在任何餐厅上班，他站在大街上喊了一句"我在营业！"——他说的"我"指的是**他自己这个独立个体**（全局对象），不是任何餐厅。

~~~javascript
// ========== 非严格模式：this = window ==========
function 报名() {
  console.log(this);
}
报名();  // window（浏览器中）/ global（Node.js 中）

// ========== 严格模式：this = undefined ==========
function 报名严格() {
  "use strict";
  console.log(this);
}
报名严格();  // undefined

// ========== 变量中的函数被直接调用 ==========
const 餐厅 = {
  名字: "老王饭馆",
  报名() {
    console.log(this.名字);
  }
};

const 取出的函数 = 餐厅.报名;  // 把函数取出来赋给变量
取出的函数();  // undefined（this = window，window.名字 = undefined）

// 这就像：张师傅从老王饭馆辞职了，站在大街上喊"我们店的名字是xxx"
// 他已经不在老王饭馆了，this 不再指向老王饭馆
~~~

## 8.3 隐式绑定（对象方法调用）

**一句话解释：**
函数作为**对象的方法**被调用时，`this` 指向**调用它的那个对象**。

**餐厅比喻：**
张师傅在老王饭馆上班——他说"我们店"，指的是**老王饭馆**。因为他是**被老王饭馆调用的**。

~~~javascript
// ========== 基本隐式绑定 ==========
const 餐厅 = {
  名字: "老王饭馆",
  报名() {
    console.log(`这里是${this.名字}`);
  }
};

餐厅.报名();  // 这里是老王饭馆
// ↑ 调用者是餐厅，所以 this = 餐厅

// ========== 嵌套对象：看最后一层 ==========
const 集团 = {
  名字: "老王集团",
  分店: {
    名字: "老王饭馆·北京店",
    报名() {
      console.log(this.名字);
    }
  }
};

集团.分店.报名();  // 老王饭馆·北京店
// ↑ 调用者是 集团.分店，所以 this = 分店，不是 集团

// ========== 隐式丢失 ==========
const 餐厅2 = {
  名字: "老王饭馆",
  报名() {
    console.log(`这里是${this.名字}`);
  }
};

const 变量 = 餐厅2.报名;  // 把方法取出来
变量();  // undefined（隐式丢失！this 变成了 window）
// 就像张师傅从餐厅辞职了，"我们店"就不再指向那个餐厅了

// 回调中也会隐式丢失
function 延迟执行(回调) {
  回调();  // 直接调用，没有对象前缀
}
延迟执行(餐厅2.报名);  // undefined（隐式丢失）
~~~

## 8.4 显式绑定（call / apply / bind）

**一句话解释：**
不管函数怎么调用，**你手动指定** `this` 指向谁。`call`、`apply`、`bind` 三个方法都可以做到。

**餐厅比喻：**
张师傅今天被**借调**到老李饭馆干活。虽然他的工牌上写着"老王饭馆"，但今天说"我们店"指的是**老李饭馆**——因为老板明确说了"你今天为老李饭馆服务"。

### call（逐个传参）

~~~javascript
// ========== call：指定 this，逐个传参 ==========
function 报名(城市, 区域) {
  console.log(`${this.名字}，位于${城市}${区域}`);
}

const 老王饭馆 = { 名字: "老王饭馆" };
const 老李饭馆 = { 名字: "老李饭馆" };

报名.call(老王饭馆, "北京", "朝阳区");
// 老王饭馆，位于北京朝阳区
// ↑ this = 老王饭馆，参数逐个传入

报名.call(老李饭馆, "上海", "浦东区");
// 老李饭馆，位于上海浦东区
// ↑ this = 老李饭馆

// ========== call 借用方法 ==========
const 厨师A = {
  名字: "张师傅",
  做菜(菜名) {
    console.log(`${this.名字}做了${菜名}`);
  }
};

const 厨师B = { 名字: "李师傅" };

厨师A.做菜.call(厨师B, "红烧肉");  // 李师傅做了红烧肉
// ↑ 借用厨师A的做菜方法，但 this 指向厨师B
~~~

### apply（数组传参）

~~~javascript
// ========== apply：指定 this，用数组传参 ==========
function 报名(城市, 区域) {
  console.log(`${this.名字}，位于${城市}${区域}`);
}

const 老王饭馆 = { 名字: "老王饭馆" };

// call 逐个传
报名.call(老王饭馆, "北京", "朝阳区");

// apply 数组传（效果完全一样）
报名.apply(老王饭馆, ["北京", "朝阳区"]);

// ========== apply 的常见用法：配合 Math.max ==========
const 价格们 = [38, 22, 45, 12, 68];

// Math.max 不能直接接收数组
// Math.max(价格们);       // NaN
// Math.max(38, 22, 45);  // 可以，但要逐个传

// 用 apply 展开数组
const 最高价 = Math.max.apply(null, 价格们);
console.log(最高价);  // 68

// 现代写法：用展开运算符代替 apply
const 最高价2 = Math.max(...价格们);
console.log(最高价2);  // 68
~~~

### bind（返回新函数，永久绑定 this）

~~~javascript
// ========== bind：不立即执行，返回一个 this 被永久绑定的新函数 ==========
function 报名(城市, 区域) {
  console.log(`${this.名字}，位于${城市}${区域}`);
}

const 老王饭馆 = { 名字: "老王饭馆" };

// call/apply：立即执行
报名.call(老王饭馆, "北京", "朝阳区");  // 立即执行

// bind：不执行，返回新函数
const 老王报名 = 报名.bind(老王饭馆);
// ↑ 返回一个新函数，this 永久绑定为 老王饭馆

老王报名("北京", "朝阳区");  // 老王饭馆，位于北京朝阳区
老王报名("上海", "浦东区");  // 老王饭馆，位于上海浦东区

// ========== bind 的 this 无法被覆盖 ==========
const 老李饭馆 = { 名字: "老李饭馆" };
老王报名.call(老李饭馆, "广州", "天河区");
// 老王饭馆，位于广州天河区  ← 还是老王饭馆！bind 绑定的 this 无法覆盖

// ========== bind 预设参数（柯里化） ==========
function 做菜(厨师, 菜名, 价格) {
  console.log(`${厨师}做了${菜名}，${价格}元`);
}

const 张师傅做菜 = 做菜.bind(null, "张师傅");
// ↑ this 不关心，但第一个参数预设为 "张师傅"

张师傅做菜("红烧肉", 38);  // 张师傅做了红烧肉，38元
张师傅做菜("麻婆豆腐", 22); // 张师傅做了麻婆豆腐，22元

// ========== bind 的实际用途：回调中保持 this ==========
const 餐厅 = {
  名字: "老王饭馆",
  初始化() {
    // 问题：回调里的 this 丢失了
    // setTimeout(function() {
    //   console.log(this.名字);  // undefined（this = window）
    // }, 1000);

    // 解决1：bind
    setTimeout(function() {
      console.log(this.名字);  // 老王饭馆
    }.bind(this), 1000);

    // 解决2：箭头函数（继承外层 this）
    setTimeout(() => {
      console.log(this.名字);  // 老王饭馆
    }, 1000);
  }
};
~~~

### call / apply / bind 对比

| | call | apply | bind |
|---|---|---|---|
| 作用 | 指定 this 并立即调用 | 指定 this 并立即调用 | 指定 this，返回新函数 |
| 参数传递 | 逐个传（逗号分隔） | 数组传 | 逐个传（可预设） |
| 是否立即执行 | ✅ 立即 | ✅ 立即 | ❌ 不执行，返回函数 |
| this 能否覆盖 | 后续 call/apply 可覆盖 | 后续 call/apply 可覆盖 | ❌ 绑定后不可覆盖 |
| 餐厅比喻 | 张师傅今天去老李饭馆干活 | 同上，参数用清单交 | 张师傅永远为老王饭馆服务 |

~~~javascript
function 测试(甲, 乙, 丙) {
  console.log(this.名字, 甲, 乙, 丙);
}
const 对象 = { 名字: "老王" };

测试.call(对象, 1, 2, 3);          // 老王 1 2 3（逐个传参，立即执行）
测试.apply(对象, [1, 2, 3]);       // 老王 1 2 3（数组传参，立即执行）
const 新函数 = 测试.bind(对象, 1);  // 不执行，预设 this 和第一个参数
新函数(2, 3);                        // 老王 1 2 3（调用时传剩余参数）
~~~

## 8.5 new 绑定

**一句话解释：**
用 `new` 关键字调用构造函数时，`this` 指向**新创建的那个空对象**。

**餐厅比喻：**
你用蓝图（构造函数）开了一家**新餐厅**——`this` 就指向这家**刚开的新餐厅**，你往上面挂什么属性，它就有什么属性。

~~~javascript
// ========== new 绑定 ==========
function 餐厅(名字, 地址) {
  // new 做了4件事：
  // 1. 创建一个空对象 {}
  // 2. 把 this 指向这个空对象
  // 3. 执行函数体，给 this 添加属性
  // 4. 返回 this

  this.名字 = 名字;
  this.地址 = 地址;
  this.报名 = function() {
    console.log(`欢迎来到${this.名字}，地址：${this.地址}`);
  };
}

const 老王饭馆 = new 餐厅("老王饭馆", "北京朝阳区");
const 老李饭馆 = new 餐厅("老李饭馆", "上海浦东区");

老王饭馆.报名();  // 欢迎来到老王饭馆，地址：北京朝阳区
老李饭馆.报名();  // 欢迎来到老李饭馆，地址：上海浦东区

console.log(老王饭馆.名字);  // 老王饭馆
console.log(老李饭馆.名字);  // 老李饭馆

// this 指向新创建的对象
console.log(老王饭馆 instanceof 餐厅);  // true
~~~

## 8.6 箭头函数的 this（没有自己的 this）

**一句话解释：**
箭头函数**没有自己的 `this`**，它的 `this` 继承自**外层作用域的 `this`**（词法作用域，定义时就确定了）。

**餐厅比喻：**
箭头函数就像一个**临时工**——他没有自己的工位（没有自己的 this），他借用了隔壁**正式工的工位**（外层的 this）。不管谁叫他干活，他永远坐在那个正式工的工位上。

~~~javascript
// ========== 箭头函数继承外层 this ==========
const 餐厅 = {
  名字: "老王饭馆",
  员工们: ["张师傅", "李师傅", "王师傅"],

  报名() {
    // 普通函数的 this = 调用者
    // 箭头函数的 this = 外层的 this（即餐厅）

    this.员工们.forEach((员工) => {
      // ↑ 箭头函数：this 继承自外层的报名() 的 this，即餐厅
      console.log(`${员工}在${this.名字}工作`);
    });
  }
};

餐厅.报名();
// 张师傅在老王饭馆工作
// 李师傅在老王饭馆工作
// 王师傅在老王饭馆工作

// ========== 如果用普通函数，this 会丢失 ==========
const 餐厅2 = {
  名字: "老王饭馆",
  员工们: ["张师傅", "李师傅"],

  报名() {
    this.员工们.forEach(function(员工) {
      // ↑ 普通函数：this = window（回调中隐式丢失）
      console.log(`${员工}在${this.名字}工作`);  // this.名字 = undefined
    });
  }
};

餐厅2.报名();
// 张师傅在undefined工作
// 李师傅在undefined工作

// ========== 箭头函数的 this 无法被 call/apply/bind 改变 ==========
const 普通函数 = function() {
  console.log(this.名字);
};

const 箭头函数 = () => {
  console.log(this.名字);  // 继承外层 this
};

const 对象 = { 名字: "老王饭馆" };

普通函数.call(对象);  // 老王饭馆（call 可以改变普通函数的 this）
箭头函数.call(对象);  // undefined（call 无法改变箭头函数的 this）
~~~

## 8.7 优先级规则

**一句话解释：**
当多种绑定规则同时存在时，按优先级从高到低：**new 绑定 > 显式绑定 > 隐式绑定 > 默认绑定**。

**餐厅比喻：**
张师傅同时收到了四个邀请：
1. **新餐厅开业要他当主厨**（new 绑定）—— 优先级最高
2. **老板说"今天去老李饭馆"**（显式绑定）
3. **老王饭馆叫他回去上班**（隐式绑定）
4. **他自己在大街上站着**（默认绑定）—— 优先级最低

他按优先级选择：新餐厅 > 老板指定 > 叫他的餐厅 > 大街上

~~~javascript
// ========== new 绑定 > 显式绑定 ==========
function 餐厅(名字) {
  this.名字 = 名字;
}

const 绑定函数 = 餐厅.bind({ 名字: "老李饭馆" });  // 显式绑定

const 新餐厅 = new 绑定函数("新餐厅");  // new 绑定
console.log(新餐厅.名字);  // 新餐厅（new 赢了！bind 被覆盖）

// ========== 显式绑定 > 隐式绑定 ==========
const 老王饭馆 = {
  名字: "老王饭馆",
  报名() {
    console.log(this.名字);
  }
};

const 老李饭馆 = { 名字: "老李饭馆" };

老王饭馆.报名();                          // 老王饭馆（隐式绑定）
老王饭馆.报名.call(老李饭馆);              // 老李饭馆（显式绑定赢了！）

// ========== 隐式绑定 > 默认绑定 ==========
function 报名() {
  console.log(this.名字);
}

const 餐厅3 = {
  名字: "老王饭馆",
  报名: 报名
};

报名();          // undefined（默认绑定：this = window）
餐厅3.报名();    // 老王饭馆（隐式绑定赢了！）
~~~

### 优先级速查表

| 优先级 | 绑定方式 | 判断条件 | this 指向 |
|---|---|---|---|
| 1（最高） | new 绑定 | `new 函数()` | 新创建的对象 |
| 2 | 显式绑定 | `call/apply/bind` | 指定的对象 |
| 3 | 隐式绑定 | `对象.方法()` | 调用的对象 |
| 4（最低） | 默认绑定 | 直接调用 `函数()` | window / undefined |

~~~javascript
// ========== 快速判断 this 的四步法 ==========
function 判断this() {
  console.log(this);
}

const 对象 = { 名字: "老王", 判断this };

// 1. 是 new 调用的吗？ → this = 新对象
new 判断this();

// 2. 是 call/apply/bind 调用的吗？ → this = 指定的对象
判断this.call(对象);

// 3. 是通过对象调用的吗？ → this = 那个对象
对象.判断this();

// 4. 以上都不是 → 默认绑定
判断this();
~~~

## 8.8 常见 this 陷阱与解决方案

### 陷阱1：回调中 this 丢失

~~~javascript
const 餐厅 = {
  名字: "老王饭馆",
  初始化() {
    // ❌ 错误：回调中 this 丢失
    // setTimeout(function() {
    //   console.log(this.名字);  // undefined
    // }, 1000);

    // ✅ 解决1：箭头函数（推荐）
    setTimeout(() => {
      console.log(this.名字);  // 老王饭馆
    }, 1000);

    // ✅ 解决2：bind
    setTimeout(function() {
      console.log(this.名字);  // 老王饭馆
    }.bind(this), 1000);

    // ✅ 解决3：保存 this 到变量
    const self = this;
    setTimeout(function() {
      console.log(self.名字);  // 老王饭馆
    }, 1000);
  }
};
~~~

### 陷阱2：方法被赋值给变量后 this 丢失

~~~javascript
const 餐厅 = {
  名字: "老王饭馆",
  报名() {
    console.log(`这里是${this.名字}`);
  }
};

// ❌ 陷阱：方法被取出来后，隐式绑定丢失
const 变量 = 餐厅.报名;
变量();  // undefined（this = window）

// ✅ 解决：bind 永久绑定
const 绑定变量 = 餐厅.报名.bind(餐厅);
绑定变量();  // 这里是老王饭馆

// ✅ 解决：箭头函数在定义时就绑定了
const 餐厅2 = {
  名字: "老王饭馆",
  // 箭头函数：this 在定义时就确定为外层的 this
  // 但注意：对象字面量的 {} 不是作用域，外层 this 是 window
  // 所以这种方式不适用于对象字面量

  // 推荐：在 constructor 或方法内部用箭头函数
};
~~~

### 陷阱3：DOM 事件中的 this

~~~javascript
// ========== 事件处理函数中的 this ==========
// 在 DOM 事件中，普通函数的 this 指向触发事件的元素

// document.querySelector("button").addEventListener("click", function() {
//   console.log(this);  // <button>（触发事件的 DOM 元素）
//   this.textContent = "已点击";  // this 指向按钮元素
// });
~~~

### 陷阱4：class 中的方法 this 丢失

~~~javascript
class 餐厅 {
  constructor(名字) {
    this.名字 = 名字;
  }

  报名() {
    console.log(`这里是${this.名字}`);
  }
}

const 老王饭馆 = new 餐厅("老王饭馆");
老王饭馆.报名();  // 这里是老王饭馆

const 变量 = 老王饭馆.报名;
// 变量();  // ❌ TypeError: Cannot read properties of undefined
// class 内部默认是严格模式，this = undefined

// ✅ 解决1：bind
const 绑定变量 = 老王饭馆.报名.bind(老王饭馆);
绑定变量();  // 这里是老王饭馆

// ✅ 解决2：在 constructor 中用箭头函数绑定（Vue 项目常用）
class 餐厅2 {
  constructor(名字) {
    this.名字 = 名字;
    this.报名 = () => {
      console.log(`这里是${this.名字}`);
    };
  }
}

const 老李饭馆 = new 餐厅2("老李饭馆");
const 变量2 = 老李饭馆.报名;
变量2();  // 这里是老李饭馆（箭头函数的 this 继承自 constructor）
~~~

## 第08章 总结

| 术语 | 一句话解释 | 餐厅比喻关键词 |
|---|---|---|
| this | 函数被调用时的"主人" | "我们店"指的是哪家店 |
| 默认绑定 | 直接调用，this = window/undefined | 站在大街上喊"我在营业" |
| 隐式绑定 | 对象方法调用，this = 对象 | 张师傅在老王饭馆，"我们店"= 老王饭馆 |
| 隐式丢失 | 方法被取出后调用，this 丢失 | 从餐厅辞职了，"我们店"不知道指谁 |
| 显式绑定 call | 手动指定 this，逐个传参，立即执行 | 被借调到老李饭馆，逐个报告 |
| 显式绑定 apply | 手动指定 this，数组传参，立即执行 | 同上，但用清单报告 |
| 显式绑定 bind | 手动指定 this，返回新函数，不执行 | 永久借调，但不马上上班 |
| new 绑定 | new 调用构造函数，this = 新对象 | 用蓝图开新餐厅 |
| 箭头函数 this | 没有自己的 this，继承外层 | 临时工借用工位，永远在那个位置 |
| 优先级 | new > 显式 > 隐式 > 默认 | 新餐厅开业 > 老板指定 > 餐厅叫你 > 大街上 |
| this 陷阱 | 回调丢失 / 变量赋值丢失 / DOM / class | 辞职后"我们店"不知道指谁 |
| 解决方案 | 箭头函数 / bind / 保存 self | 给临时工固定工位 / 永久借调 / 写纸条记住 |
