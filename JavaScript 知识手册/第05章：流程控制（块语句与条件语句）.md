# 第05章：流程控制（块语句与条件语句）

## 5.1 块语句 / 标签（Label）

### 块语句

**一句话解释：**
块语句就是用一对花括号 `{ }` 把多条语句包起来，组成一个"块"。它常用于 `if`、`for`、`while` 等控制结构中，控制"哪些代码属于一起执行"。

**餐厅比喻：**
块语句就像**一张"流程卡"**——你把一组动作写在一张卡片上，然后说"如果今天下雨，就按这张卡片上的步骤做"。

~~~javascript
// 基本块语句
{
  const 食材 = "鸡肉";
  const 调料 = "辣椒、花椒";
  console.log(`用${调料}炒${食材}`);
}

// if + 块语句
const 是否下雨 = true;
if (是否下雨) {
  console.log("带上雨伞");
  console.log("穿上雨靴");
  console.log("出门小心");
}
// 如果不加 { }，只有第一行 console.log 属于 if
~~~

### 标签（Label）

**一句话解释：**
标签就是给循环或代码块**起个名字**，然后可以用 `break` 或 `continue` 按名字精确控制"跳出哪一层"或"跳过哪一层"。

**餐厅比喻：**
想象你同时负责三层楼的巡视，每层楼都有编号。当你在三楼发现紧急情况，你说"**我从三楼撤！**"（`break 三楼`），别人就知道你从哪一层出来了。标签就是**给每一层楼起个名字**。

~~~javascript
// ========== 基本标签语法 ==========
标签名: 语句;

// ========== 标签 + break：跳出指定循环 ==========
外层: for (let 楼层 = 1; 楼层 <= 3; 楼层++) {
  内层: for (let 房间 = 1; 房间 <= 3; 房间++) {
    if (楼层 === 2 && 房间 === 2) {
      console.log(`在${楼层}楼${房间}号房发现火情，紧急撤离！`);
      break 外层;  // 直接跳出外层循环（不是只跳出内层）
    }
  }
}
// 输出：在2楼2号房发现火情，紧急撤离！
// 然后整个循环结束（两层都停了）

// ========== 如果不用标签，break 只跳出当前层 ==========
for (let 楼层 = 1; 楼层 <= 3; 楼层++) {
  for (let 房间 = 1; 房间 <= 3; 房间++) {
    if (楼层 === 2 && 房间 === 2) {
      break;  // 只跳出内层循环，外层继续
    }
  }
  console.log(`${楼层}楼巡视完毕`);  // 每层都会执行
}
// 1楼巡视完毕
// 2楼巡视完毕
// 3楼巡视完毕

// ========== 标签 + continue：跳过指定循环的当次迭代 ==========
外层: for (let 楼层 = 1; 楼层 <= 3; 楼层++) {
  内层: for (let 房间 = 1; 房间 <= 3; 房间++) {
    if (房间 === 2) {
      continue 外层;  // 跳过外层循环的当次迭代（直接去下一个楼层）
    }
    console.log(`检查${楼层}楼${房间}号房`);
  }
}
// 检查1楼1号房  ← 到1楼2号房时跳到下一楼层
// 检查2楼1号房
// 检查3楼1号房
~~~

## 5.2 条件语句

### if / if...else / if...else if...else

**一句话解释：**
根据条件决定执行哪段代码——满足条件就执行 `{ }` 里的代码，不满足就跳过（或执行 else 里的代码）。

~~~javascript
// ========== if：只在条件为真时执行 ==========
const 利润 = 2500;

if (利润 > 2000) {
  console.log("今天表现不错，加个菜！");  // ✅ 会执行
}

// ========== if...else：二选一 ==========
const 是否下雨 = true;

if (是否下雨) {
  console.log("带伞出门");
} else {
  console.log("直接出门");
}

// ========== if...else if...else：多选一 ==========
const 利润2 = 800;

if (利润2 > 2000) {
  console.log("表现优秀，全员奖励！");
} else if (利润2 > 1000) {
  console.log("表现不错，继续保持。");
} else if (利润2 > 500) {
  console.log("勉强及格，还需努力。");
} else {
  console.log("亏损了，要调整策略。");
}
~~~

### 三元运算符

**一句话解释：**
三元运算符是 `if...else` 的简写形式——`条件 ? 条件为真时的值 : 条件为假时的值`。适合简短的二选一赋值。

~~~javascript
const 利润 = 1800;

// ========== if...else 写法 ==========
let 状态;
if (利润 > 1500) {
  状态 = "盈利";
} else {
  状态 = "亏损";
}
console.log(状态);  // 盈利

// ========== 三元运算符写法（更简洁） ==========
const 状态2 = 利润 > 1500 ? "盈利" : "亏损";
console.log(状态2);  // 盈利

// ========== 三元运算符也可以嵌套（但不推荐太深） ==========
const 利润3 = 2500;
const 等级 = 利润3 > 2000 ? "优秀" : 利润3 > 1000 ? "良好" : "一般";
console.log(等级);  // 优秀

// ========== 在模板字符串中使用 ==========
const 今日利润 = 2000;
console.log(`今日${今日利润 > 0 ? "盈利" : "亏损"}${Math.abs(今日利润)}元`);
// 今日盈利2000元
~~~

### switch

**一句话解释：**
当你要根据一个变量的**不同值**执行不同的代码时，`switch` 比一长串 `if...else if` 更清晰。

~~~javascript
// ========== 基本 switch ==========
const 菜品 = "麻婆豆腐";

switch (菜品) {
  case "红烧肉":
    console.log("38元，需要炖40分钟");
    break;  // 不写 break 会继续执行下一个 case！
  case "麻婆豆腐":
    console.log("22元，需要炒5分钟");
    break;
  case "糖醋里脊":
    console.log("45元，需要炸+炒");
    break;
  default:
    console.log("没有这道菜");
}
// 输出：22元，需要炒5分钟

// ========== break 的重要性：没有 break 会"穿透" ==========
const 等级 = "A";

switch (等级) {
  case "A":
    console.log("优秀");     // 执行
    // 没有 break！继续往下执行！
  case "B":
    console.log("良好");     // 也会执行！（穿透了）
    // 没有 break！继续往下执行！
  case "C":
    console.log("及格");     // 也会执行！（穿透了）
    break;
  default:
    console.log("不及格");
}
// 输出：优秀 良好 及格（三个都执行了！）

// ========== 穿透的正当用法：多个值执行同一段代码 ==========
const 月份 = 7;

switch (月份) {
  case 3: case 4: case 5:
    console.log("春天");    // 3、4、5月都执行这行
    break;
  case 6: case 7: case 8:
    console.log("夏天");    // 6、7、8月都执行这行
    break;
  case 9: case 10: case 11:
    console.log("秋天");
    break;
  case 12: case 1: case 2:
    console.log("冬天");
    break;
}

// ========== switch 使用严格相等（===）比较 ==========
const 值 = "1";

switch (值) {
  case 1:
    console.log("数字1");   // 不会执行！
    break;
  case "1":
    console.log("字符串1"); // ✅ 会执行（类型和值都匹配）
    break;
}
// "1" === 1 → false，类型不同不会匹配
~~~

### 逻辑短路（&& / || / ??）

**一句话解释：**
逻辑运算符在能确定结果时就**立即停止**（短路），不再计算后面的表达式。

~~~javascript
// ========== &&（逻辑与）：第一个为假就停，返回第一个假值 ==========
console.log(false && "不会执行");    // false（短路，不看后面）
console.log(0 && "不会执行");        // 0
console.log("" && "不会执行");       // ""
console.log(null && "不会执行");     // null
console.log(true && "会执行");       // "会执行"（第一个为真，继续看后面）
console.log("红烧肉" && "麻婆豆腐"); // "麻婆豆腐"（两个都真，返回最后一个）

// 实际用法：条件执行
const 菜品 = "红烧肉";
菜品 && console.log(`有${菜品}`);  // 有红烧肉（菜品是真值才执行）

// ========== ||（逻辑或）：第一个为真就停，返回第一个真值 ==========
console.log(true || "不会执行");     // true（短路）
console.log("红烧肉" || "不会执行"); // "红烧肉"（短路）
console.log(false || "默认菜");      // "默认菜"（第一个是假，看后面）
console.log(0 || 42);               // 42
console.log("" || "默认值");        // "默认值"
console.log(null || undefined || "找到了"); // "找到了"

// 实际用法：提供默认值（有值就用，没值用默认的）
const 用户输入 = "";
const 显示值 = 用户输入 || "未输入";
console.log(显示值);  // "未输入"（空字符串是假值，被跳过了）

// ========== ??（空值合并）：只在 null 或 undefined 时才取后面的值 ==========
console.log(null ?? "默认值");      // "默认值"（null，取后面的）
console.log(undefined ?? "默认值"); // "默认值"（undefined，取后面的）
console.log(0 ?? "默认值");         // 0（不是 null/undefined，保留！）
console.log("" ?? "默认值");        // ""（不是 null/undefined，保留！）
console.log(false ?? "默认值");     // false（不是 null/undefined，保留！）

// ========== || vs ?? 的关键区别 ==========
const 桌号 = 0;
const 菜单文字 = "";

// || 把 0 和 "" 也当成假值跳过了
console.log(桌号 || 未指定);          // "未指定" ← 0 被跳过了！
console.log(菜单文字 || "空");         // "空"     ← "" 被跳过了！

// ?? 只看 null 和 undefined，0 和 "" 不受影响
console.log(桌号 ?? "未指定");         // 0     ← 0 被保留了！
console.log(菜单文字 ?? "空");         // ""    ← "" 被保留了！
~~~

## 5.3 条件语句对比速查

| 方式 | 适用场景 | 餐厅比喻 |
|---|---|---|
| `if` | 只在条件为真时执行 | 如果下雨，带上伞 |
| `if...else` | 二选一 | 如果下雨带伞，否则直接走 |
| `if...else if...else` | 多选一（条件可以是任意表达式） | 按利润高低给不同评语 |
| `三元运算符 ? :` | 简短的二选一**赋值** | 一句话问清，直接给答案 |
| `switch` | 根据一个变量的**固定值**走不同分支 | 按菜品名查价格 |
| `&&` 短路 | 条件为真时才执行后面 | 有菜才通知厨房 |
| `\|\|` 短路 | 提供默认值（但 0 和 "" 也会被跳过） | 没有菜单就用默认菜单 |
| `??` 空值合并 | 只在 null/undefined 时提供默认值 | 只有"真的没有"才用默认的 |

| if | 条件为真时执行 | 如果下雨，带上伞 |
| if...else | 二选一 | 如果下雨带伞，否则直接走 |

| break in switch | 阻止穿透（不加会继续执行下一个 case） | 拿完红烧肉就停，不拿麻婆豆腐 |
