---

## 核心策略：6 个套路

1. **Prompt 基础** → System Prompt 就是"老板给员工的工作手册"，Temperature 就是"员工的创意程度"
2. **Prompt 进阶** → Few-Shot 就是"给员工看几个例子"，CoT 就是"让员工一步步想"
3. **Function Calling** → 就是"给 AI 一张工具清单，AI 自己决定用哪个工具"
4. **ReAct 模式** → AI 的工作流程：想一想（Thought）→ 做一做（Action）→ 看一看（Observation）
5. **记忆系统** → 对话历史就是"把之前的聊天记录一起发给 AI"
6. **MCP 协议** → 就是"给 AI 工具定一个统一的插头标准"

### 1.1 最简单的对话

创建文件 `demo1_第一次对话.py`：

~~~python
# ========== demo1_第一次对话.py
# 这是你和 AI 的第一次对话！

from openai import OpenAI
from dotenv import load_dotenv
import os

# 加载 .env 文件中的环境变量
load_dotenv()

# 创建 OpenAI 客户端（类似前端创建 axios 实例）
客户端 = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),
)

# ========== 发送消息并获取回复
# messages 是一个数组，每个元素有 role（角色）和 content（内容）
# 就像微信群聊：每条消息都有"谁发的"和"内容"
回复 = 客户端.chat.completions.create(
    model="gpt-4o-mini",      # 用哪个模型（类似选择用哪个版本的库）
    messages=[
        {
            "role": "system",     # system = 系统提示词（给 AI 的"工作手册"）
            "content": "你是一个友好的餐厅服务员，用简洁的中文回答问题。",
        },
        {
            "role": "user",       # user = 用户说的话
            "content": "你们有什么推荐的菜吗？",
        },
    ],
    temperature=0.7,     # 温度：0=严格确定，1=非常随机（后面详细讲）
    max_tokens=500,      # 最多回复多少个 token
)

# 获取 AI 的回复
回答 = 回复.choices[0].message.content
print(f"AI: {回答}")

# ========== 查看 token 消耗（计费依据）
print(f"\n--- Token 统计 ---")
print(f"输入 tokens: {回复.usage.prompt_tokens}")
print(f"输出 tokens: {回复.usage.completion_tokens}")
print(f"总计 tokens: {回复.usage.total_tokens}")
# 为什么重要？因为 API 按 token 收费！
# gpt-4o-mini: 输入 $0.15/1M tokens，输出 $0.60/1M tokens
~~~

运行：

~~~bash
python3 demo1_第一次对话.py
# 你会看到 AI 以餐厅服务员的身份回复你
~~~

### 1.2 多轮对话

在 `demo1_第一次对话.py` 末尾追加：

~~~python
# ========== 多轮对话
# 关键理解：每次请求都要把完整的对话历史发给 AI
# AI 本身没有"记忆"，它只看当前这次请求里的 messages

对话历史 = [
    {"role": "system", "content": "你是一个友好的餐厅服务员。"},
]

# 模拟多轮对话
用户说的话列表 = [
    "你好，我想点菜",
    "有什么推荐吗？",
    "宫保鸡丁多少钱？",
    "来一份，再加一碗米饭",
]

for 用户说的话 in 用户说的话列表:
    # 1. 把用户的话加到历史中
    对话历史.append({"role": "user", "content": 用户说的话})

    # 2. 把完整历史发给 AI
    回复 = 客户端.chat.completions.create(
        model="gpt-4o-mini",
        messages=对话历史,   # 注意：是整个历史，不是只发最新一条！
        temperature=0.7,
    )

    # 3. 把 AI 的回复也加到历史中
    AI回复 = 回复.choices[0].message.content
    对话历史.append({"role": "assistant", "content": AI回复})

    print(f"用户: {用户说的话}")
    print(f"AI: {AI回复}")
    print("---")

# 查看完整对话历史
print(f"\n对话历史共 {len(对话历史)} 条消息")
~~~

运行验证：

~~~bash

# 确认 AI 能记住之前的对话内容
~~~

### 1.3 流式输出（stream）

创建文件 `demo1_流式输出.py`：

~~~python
# ========== demo1_流式输出.py
# 流式输出 = AI 一个字一个字往外蹦，而不是全部想好了一次性返回
# 就像 ChatGPT 网页上看到的"打字"效果

from openai import OpenAI
from dotenv import load_dotenv
import os

load_dotenv()
客户端 = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),
)

# ========== 普通模式（等全部生成完才返回）
print("=== 普通模式 ===")
回复 = 客户端.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "用3句话介绍Python"}],
    stream=False,  # 不流式，等全部完成
)
print(回复.choices[0].message.content)

# ========== 流式模式（一个 token 一个 token 返回）
print("\n=== 流式模式 ===")
流 = 客户端.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "用3句话介绍JavaScript"}],
    stream=True,  # 开启流式输出
)

# 逐个 token 读取
for 数据块 in 流:
    # 每个数据块包含一个或多个 token
    内容 = 数据块.choices[0].delta.content
    if 内容:    # 可能为空（开始和结束时）
        print(内容, end="", flush=True)  # end="" 不换行，flush=True 立即输出

print()  # 最后换行
~~~

运行：

~~~bash
python3 demo1_流式输出.py
# 你会看到"流式模式"的文字像打字一样一个一个蹦出来
~~~

### 1.4 接入 FastAPI（SSE 流式接口）

创建文件 `demo1_AI接口.py`——把 AI 能力包装成后端 API：

~~~python
# ========== demo1_AI接口.py
# 把 AI 对话能力包装成 FastAPI 接口，前端可以通过 SSE 接收流式输出

from fastapi import FastAPI
from fastapi.responses import StreamingResponse, HTMLResponse
from openai import OpenAI
from dotenv import load_dotenv
import os
import json

load_dotenv()

厨房 = FastAPI(title="AI 对话接口")

客户端 = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),
)

# ========== 流式对话接口
async def 生成AI回复(消息列表: list[dict]):
    """流式生成 AI 回复"""
    流 = 客户端.chat.completions.create(
        model="gpt-4o-mini",
        messages=消息列表,
        stream=True,
        temperature=0.7,
        max_tokens=1000,
    )

    for 数据块 in 流:
        内容 = 数据块.choices[0].delta.content
        if 内容:
            yield f"data: {json.dumps({'类型': '内容', '字符': 内容}, ensure_ascii=False)}\n\n"

    # 发送完成信号
    yield f"data: {json.dumps({'类型': '完成'}, ensure_ascii=False)}\n\n"


@厨房.post("/聊天")
async def 聊天接口(body: dict):
    """
    POST /聊天
    Body: {"消息": "你好", "系统提示": "你是餐厅服务员"}
    """
    系统提示 = body.get("系统提示", "你是一个友好的助手。")
    用户消息 = body.get("消息", "")

    消息列表 = [
        {"role": "system", "content": 系统提示},
        {"role": "user", "content": 用户消息},
    ]

    return StreamingResponse(
        生成AI回复(消息列表),
        media_type="text/event-stream",
        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"},
    )


# ========== 内置测试页面
@厨房.get("/", response_class=HTMLResponse)
def 测试页面():
    return """

                    border-radius: 6px; color: #c9d1d9; font-size: 14px; outline: none; }

            button:disabled { opacity: 0.5; cursor: not-allowed; }

    </head>

        <div class="header"><h1>AI 餐厅助手</h1></div>
        <div class="messages" id="消息列表"></div>
        <div class="input-area">

                }

                发送按钮.disabled = false;
                输入框.focus();
            }
        </script>

    </html>
    """
~~~

### 2.1 Temperature 和 Top-P

创建文件 `demo2_参数调优.py`：

~~~python
# ========== demo2_参数调优.py

from openai import OpenAI
from dotenv import load_dotenv
import os

load_dotenv()
客户端 = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),
)

消息 = [{"role": "user", "content": "给我推荐一道菜，用一句话描述"}]


# ========== Temperature（温度）控制"创意程度"
# 前端理解：就像一个"随机性滑块"
#   0.0 = 最确定（每次回答几乎一样）→ 适合：代码生成、数学计算
#   0.7 = 适度创意（推荐默认值）     → 适合：日常对话
#   1.0+ = 非常随机（可能很有趣，也可能胡说）→ 适合：创意写作

print("=== Temperature 对比（同一问题问3次）===")

for 温度 in [0.0, 0.7, 1.2]:
    print(f"\n--- Temperature = {温度} ---")
    for 次数 in range(3):
        回复 = 客户端.chat.completions.create(
            model="gpt-4o-mini",
            messages=消息,
            temperature=温度,
            max_tokens=50,
        )
        print(f"  [{次数+1}] {回复.choices[0].message.content}")


# ========== Top-P（核采样）控制"候选词范围"
# 前端理解：就像"从多少个候选词里选"
#   0.1 = 只从概率最高的 10% 词里选 → 非常保守
#   0.9 = 从概率最高的 90% 词里选   → 推荐
#   1.0 = 从所有词里选              → 最自由

# 通常建议：调一个就好，不要同时调 Temperature 和 Top-P
# 日常使用：temperature=0.7, top_p=1.0（默认值就很好）
~~~

运行：

~~~bash
python3 demo2_参数调优.py
# 观察：
#   Temperature=0.0 时，3次回答几乎一样
#   Temperature=0.7 时，有些变化但不离谱
#   Temperature=1.2 时，回答差异很大，可能很有趣也可能不靠谱
~~~

## Demo 3：Function Calling — 让 AI 调用你写的函数

### 学习目标

- 理解 Function Calling 的工作原理
- 定义工具函数，让 AI 自动选择调用
- 处理 AI 的调用结果并返回

### 3.1 Function Calling 原理

~~~
传统方式：用户 → AI → 直接回答（AI 只能用自己知道的知识）

Function Calling 方式：
  1. 你告诉 AI："你可以使用这些工具"（工具清单）
  2. AI 根据用户问题，决定要不要用工具，用哪个
  3. AI 输出"我要调用 XXX 函数，参数是 YYY"
  4. 你的代码执行这个函数，拿到结果
  5. 把结果发回给 AI，AI 生成最终回答

类比：AI 是一个聪明的客服，工具是它桌上的电话、电脑、查价系统
  → 客服自己不知道库存，但会帮你查电脑（调用函数）
  → 查完后用自然语言告诉你结果
~~~

### 3.2 基础 Function Calling

创建文件 `demo3_FunctionCalling.py`：

~~~python
# ========== demo3_FunctionCalling.py

from openai import OpenAI
from dotenv import load_dotenv
import os
import json

load_dotenv()
客户端 = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),
)


# ========== 第一步：定义你的"工具函数"（这是你写的代码，不是 AI 写的）

def 查询菜品信息(菜品名称: str) -> dict:
    """查询菜品的详细信息"""
    菜品库 = {
        "宫保鸡丁": {"名称": "宫保鸡丁", "价格": 38.5, "分类": "热菜", "辣度": 3, "食材": "鸡肉、花生、辣椒", "热量": "350大卡"},
        "鱼香肉丝": {"名称": "鱼香肉丝", "价格": 28.0, "分类": "热菜", "辣度": 1, "食材": "猪肉、木耳、胡萝卜", "热量": "280大卡"},
        "麻婆豆腐": {"名称": "麻婆豆腐", "价格": 22.0, "分类": "热菜", "辣度": 4, "食材": "豆腐、牛肉末、花椒", "热量": "200大卡"},
        "凉菜拼盘": {"名称": "凉菜拼盘", "价格": 18.0, "分类": "凉菜", "辣度": 0, "食材": "黄瓜、豆皮、花生", "热量": "120大卡"},
        "米饭":     {"名称": "米饭",     "价格": 3.0,  "分类": "主食", "辣度": 0, "食材": "大米",           "热量": "200大卡"},
    }
    return 菜品库.get(菜品名称, {"错误": f"没有找到'{菜品名称}'这道菜"})


def 查询库存(菜品名称: str) -> dict:
    """查询菜品库存"""
    库存 = {"宫保鸡丁": 15, "鱼香肉丝": 8, "麻婆豆腐": 20, "凉菜拼盘": 5, "米饭": 100}
    数量 = 库存.get(菜品名称, 0)
    return {"菜品": 菜品名称, "库存": 数量, "状态": "充足" if 数量 > 10 else "紧张" if 数量 > 0 else "售罄"}


def 计算订单总价(菜品列表: str) -> dict:
    """计算订单总价。菜品列表格式：'宫保鸡丁x2,鱼香肉丝x1'"""
    总价 = 0
    明细 = []
    for 项 in 菜品列表.split(","):
        名称, 数量 = 项.strip().split("x")
        信息 = 查询菜品信息(名称.strip())
        if "错误" not in 信息:
            小计 = 信息["价格"] * int(数量)
            总价 += 小计
            明细.append({"菜品": 名称.strip(), "单价": 信息["价格"], "数量": int(数量), "小计": 小计})
    return {"明细": 明细, "总价": round(总价, 2)}


# ========== 第二步：定义工具清单（告诉 AI 有哪些工具可以用）
# 这个格式是 OpenAI 规定的，必须严格按照这个结构
工具清单 = [
    {
        "type": "function",
        "function": {
            "name": "查询菜品信息",
            "description": "查询某道菜的详细信息，包括价格、分类、辣度、食材、热量",
            "parameters": {
                "type": "object",
                "properties": {
                    "菜品名称": {
                        "type": "string",
                        "description": "菜品名称，如：宫保鸡丁",
                    },
                },
                "required": ["菜品名称"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "查询库存",
            "description": "查询某道菜的库存数量和状态",
            "parameters": {
                "type": "object",
                "properties": {
                    "菜品名称": {
                        "type": "string",
                        "description": "菜品名称",
                    },
                },
                "required": ["菜品名称"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "计算订单总价",
            "description": "计算订单总价，输入格式如：宫保鸡丁x2,鱼香肉丝x1",
            "parameters": {
                "type": "object",
                "properties": {
                    "菜品列表": {
                        "type": "string",
                        "description": "菜品和数量，格式：菜品名x数量,菜品名x数量",
                    },
                },
                "required": ["菜品列表"],
            },
        },
    },
]


# ========== 第三步：让 AI 使用工具

# Python 的函数名 → 函数对象的映射（方便后面根据名字调用）
可用函数 = {
    "查询菜品信息": 查询菜品信息,
    "查询库存": 查询库存,
    "计算订单总价": 计算订单总价,
}

用户问题 = "宫保鸡丁和鱼香肉丝哪个更辣？它们今天有货吗？如果我各点两份要多少钱？"

print(f"用户: {用户问题}\n")

# 第一轮：发消息给 AI，AI 决定要不要调用工具
回复 = 客户端.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": "你是餐厅助手。使用提供的工具回答顾客问题。"},
        {"role": "user", "content": 用户问题},
    ],
    tools=工具清单,        # 告诉 AI 有哪些工具
    tool_choice="auto",    # auto = AI 自己决定用不用工具
)

消息对象 = 回复.choices[0].message

# 检查 AI 是否要调用工具
if 消息对象.tool_calls:
    print(f"AI 决定调用 {len(消息对象.tool_calls)} 个工具：\n")

    # 把 AI 的回复（含 tool_calls）加入消息历史
    消息列表 = [
        {"role": "system", "content": "你是餐厅助手。使用提供的工具回答顾客问题。"},
        {"role": "user", "content": 用户问题},
        消息对象,  # AI 的回复（包含要调用哪些工具）
    ]

    # 第四步：执行 AI 请求的每个工具调用
    for 工具调用 in 消息对象.tool_calls:
        函数名 = 工具调用.function.name
        参数 = json.loads(工具调用.function.arguments)

        print(f"  📞 调用: {函数名}({参数})")

        # 执行函数
        结果 = 可用函数[函数名](**参数)
        print(f"  📦 结果: {结果}\n")

        # 把工具执行结果加入消息列表
        消息列表.append({
            "role": "tool",
            "tool_call_id": 工具调用.id,
            "content": json.dumps(结果, ensure_ascii=False),
        })

    # 第五步：把工具结果发回 AI，让 AI 生成最终回答
    最终回复 = 客户端.chat.completions.create(
        model="gpt-4o-mini",
        messages=消息列表,
    )

    print(f"AI 最终回答: {最终回复.choices[0].message.content}")
else:
    print(f"AI 直接回答（没用工具）: {消息对象.content}")
~~~

~~~python
        消息列表.append(消息对象)

        for 调用 in 消息对象.tool_calls:
            函数名 = 调用.function.name
            参数 = json.loads(调用.function.arguments)

            # 通知前端正在调用工具
            yield f"data: {json.dumps({'类型': '工具调用', '函数': 函数名, '参数': 参数}, ensure_ascii=False)}\n\n"

            结果 = 工具函数映射[函数名](**参数)

            消息列表.append({
                "role": "tool",
                "tool_call_id": 调用.id,
                "content": json.dumps(结果, ensure_ascii=False),
            })

        流 = 客户端.chat.completions.create(
            model="gpt-4o-mini",
            messages=消息列表,
            stream=True,
        )
        for 数据块 in 流:
            内容 = 数据块.choices[0].delta.content
            if 内容:
                yield f"data: {json.dumps({'类型': '内容', '字符': 内容}, ensure_ascii=False)}\n\n"
    else:
        # AI 不需要工具，直接回答
        yield f"data: {json.dumps({'类型': '内容', '字符': 消息对象.content}, ensure_ascii=False)}\n\n"

    yield f"data: {json.dumps({'类型': '完成'}, ensure_ascii=False)}\n\n"
~~~

## Demo 4：ReAct 模式 — AI 的"思考→行动→观察"循环

### 学习目标

- 理解 ReAct（Reasoning + Acting）模式
- 实现 AI 的多步推理：想一想 → 做一做 → 看结果 → 再想
- 理解 Agent 的本质

### 4.1 ReAct 原理

~~~
ReAct = Reasoning（推理）+ Acting（行动）

循环流程：
  ┌──────────┐
  │ Thought  │ → AI 思考：我需要做什么？下一步该怎么做？
  │ (思考)    │
  └────┬─────┘
       ▼
  ┌──────────┐
  │ Action   │ → AI 行动：调用一个工具/函数
  │ (行动)    │
  └────┬─────┘
       ▼
  ┌──────────┐
  │Observation│ → AI 观察：工具返回了什么结果？
  │ (观察)    │
  └────┬─────┘
       ▼
   需要继续？ ──是──→ 回到 Thought
       │
       否
       ▼
   Final Answer（最终回答）

类比：
  你是一个新来的服务员，顾客问"有没有不辣的热菜？"
  Thought: 我需要查看菜单中哪些是热菜，再筛选出不辣的
  Action:  查询菜单
  Observation: 宫保鸡丁(辣3)、鱼香肉丝(辣1)、麻婆豆腐(辣4)
  Thought: 鱼香肉丝辣度最低(1)，但还是有点辣。让我查查有没有辣度为0的热菜
  Action:  查询辣度为0的热菜
  Observation: 红烧肉(辣0)、糖醋排骨(辣0)
  Thought: 现在我有答案了
  Answer:  推荐红烧肉和糖醋排骨，完全不辣！
~~~

~~~python
# ========== demo4_ReAct.py

from openai import OpenAI
from dotenv import load_dotenv
import os
import json

load_dotenv()
客户端 = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),

菜品库 = [
    {"名称": "宫保鸡丁", "价格": 38.5, "分类": "热菜", "辣度": 3},
    {"名称": "鱼香肉丝", "价格": 28.0, "分类": "热菜", "辣度": 1},
    {"名称": "麻婆豆腐", "价格": 22.0, "分类": "热菜", "辣度": 4},
    {"名称": "红烧肉",   "价格": 45.0, "分类": "热菜", "辣度": 0},
    {"名称": "糖醋排骨", "价格": 42.0, "分类": "热菜", "辣度": 0},
    {"名称": "凉菜拼盘", "价格": 18.0, "分类": "凉菜", "辣度": 0},
    {"名称": "米饭",     "价格": 3.0,  "分类": "主食", "辣度": 0},
]

def 查询全部菜品():
    return 菜品库

def 按条件筛选(分类: str = None, 最大辣度: int = None, 最高价格: float = None):
    结果 = 菜品库
    if 分类:
        结果 = [菜 for 菜 in 结果 if 菜["分类"] == 分类]
    if 最大辣度 is not None:
        结果 = [菜 for 菜 in 结果 if 菜["辣度"] <= 最大辣度]
    if 最高价格 is not None:
        结果 = [菜 for 菜 in 结果 if 菜["价格"] <= 最高价格]
    return 结果


# ========== ReAct 系统提示词
ReAct提示词 = """你是餐厅 AI 点餐助手。

## 工作方式（ReAct 模式）
对于每个问题，请按以下格式逐步思考和行动：

Thought: 我需要思考什么，下一步做什么
Action: 调用工具（格式：工具名(参数)）
Observation: 工具返回的结果（由系统填入，你不要自己写）
... （可以重复 Thought → Action → Observation）
Thought: 我现在有足够信息了
Answer: 最终回答用户

## 可用工具
1. 查询全部菜品() → 返回所有菜品信息
2. 按条件筛选(分类, 最大辣度, 最高价格) → 按条件筛选菜品

## 规则
- 每次只调用一个工具
- Observation 由系统填入，你不要自己编造
- 如果信息不够，继续 Thought → Action
- 确定答案后用 Answer 输出

## 示例
用户: 有什么不辣的菜？
Thought: 用户想要不辣的菜，我需要筛选辣度为0的菜品
Action: 按条件筛选(最大辣度=0)
Observation: [红烧肉(¥45), 糖醋排骨(¥42), 凉菜拼盘(¥18), 米饭(¥3)]
Thought: 我找到了4道不辣的菜，可以回答了
Answer: 我们有4道不辣的菜：红烧肉(¥45)、糖醋排骨(¥42)、凉菜拼盘(¥18)、米饭(¥3)。推荐您试试红烧肉，很受欢迎！
"""


# ========== ReAct 循环执行器
def 执行ReAct(用户问题: str, 最大轮次: int = 5):
    """执行 ReAct 循环"""
    print(f"用户: {用户问题}\n")

    对话历史 = [
        {"role": "system", "content": ReAct提示词},
        {"role": "user", "content": 用户问题},
    ]

    for 轮次 in range(最大轮次):
        print(f"--- 第 {轮次 + 1} 轮 ---")

        # 让 AI 思考
        回复 = 客户端.chat.completions.create(
            model="gpt-4o-mini",
            messages=对话历史,
            temperature=0,
            max_tokens=500,
        )

        AI输出 = 回复.choices[0].message.content
        print(AI输出)

        # 检查是否有 Answer（最终回答）
        if "Answer:" in AI输出:
            答案 = AI输出.split("Answer:")[-1].strip()
            print(f"\n✅ 最终回答: {答案}")
            return 答案

        # 检查是否有 Action（需要调用工具）
        if "Action:" in AI输出:
            Action行 = [行 for 行 in AI输出.split("\n") if 行.strip().startswith("Action:")][0]
            调用内容 = Action行.replace("Action:", "").strip()

            print(f"\n📞 执行工具: {调用内容}")

            # 执行工具
            try:
                if "查询全部菜品" in 调用内容:
                    结果 = 查询全部菜品()
                elif "按条件筛选" in 调用内容:
                    # 简单解析参数
                    import re
                    参数 = {}
                    if "最大辣度=" in 调用内容:
                        参数["最大辣度"] = int(re.search(r"最大辣度=(\d+)", 调用内容).group(1))
                    if "最高价格=" in 调用内容:
                        参数["最高价格"] = float(re.search(r"最高价格=([\d.]+)", 调用内容).group(1))
                    if "分类=" in 调用内容:
                        参数["分类"] = re.search(r'分类="([^"]+)"', 调用内容).group(1)
                    结果 = 按条件筛选(**参数)
                else:
                    结果 = {"错误": f"未知工具: {调用内容}"}
            except Exception as e:
                结果 = {"错误": str(e)}

            print(f"📦 工具结果: {结果}\n")

            # 把 AI 的输出和工具结果都加入对话历史
            对话历史.append({"role": "assistant", "content": AI输出})
            对话历史.append({"role": "user", "content": f"Observation: {json.dumps(结果, ensure_ascii=False)}"})
        else:
            # 既没有 Answer 也没有 Action，可能是纯思考
            对话历史.append({"role": "assistant", "content": AI输出})
            对话历史.append({"role": "user", "content": "请继续思考或给出最终答案。"})

    return "抱歉，我无法在限定步骤内找到答案。"
~~~

## Demo 5：记忆系统 — 让 AI 记住对话上下文

### 学习目标

- 理解 AI 的"无状态"特性
- 实现短期记忆（对话历史）
- 实现长期记忆（摘要压缩）
- 对话管理最佳实践

### 5.1 记忆原理

~~~
AI 的核心特性：无状态
  → 每次请求都是独立的，AI 不记得之前的对话
  → "记忆"的实现方式：把之前的对话内容一起发给 AI

就像打电话：
  短期记忆 = 电话里说过的话（完整对话历史）
  长期记忆 = 你记在笔记本上的重点（摘要/摘要嵌入）

问题：对话太长怎么办？
  → token 上下文窗口有限（gpt-4o-mini: 128K tokens）
  → 对话太长 = token 消耗大 = 费用高 = 响应慢
  → 解决：摘要压缩（把长对话压缩成重点）
~~~

### 5.2 实现记忆系统

创建文件 `demo5_记忆系统.py`：

~~~python
# ========== demo5_记忆系统.py

from openai import OpenAI
from dotenv import load_dotenv
import os
import json

load_dotenv()
客户端 = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),
)


class 对话管理器:
    """管理对话历史，支持短期记忆和摘要压缩"""

    def __init__(self, 系统提示: str, 最大消息数: int = 20, 摘要阈值: int = 15):
        self.系统提示 = 系统提示
        self.消息历史: list[dict] = [
            {"role": "system", "content": 系统提示},
        ]
        self.摘要: str = ""              # 长期记忆：对话摘要
        self.最大消息数 = 最大消息数       # 超过这个数就压缩
        self.摘要阈值 = 摘要阈值          # 达到这个数就开始压缩

    def 添加用户消息(self, 内容: str):
        """添加用户消息"""
        self.消息历史.append({"role": "user", "content": 内容})

    def 添加AI回复(self, 内容: str):
        """添加 AI 回复"""
        self.消息历史.append({"role": "assistant", "content": 内容})

    def 获取消息列表(self) -> list[dict]:
        """获取要发给 AI 的消息列表（含摘要）"""
        if self.摘要:
            # 把摘要作为系统消息插入
            return [
                {"role": "system", "content": self.系统提示},
                {"role": "system", "content": f"之前的对话摘要：\n{self.摘要}"},
                *self.消息历史[1:],  # 保留最近的对话
            ]
        return self.消息历史

    def 检查并压缩(self):
        """如果消息太多，自动摘要压缩"""
        # system 消息不算，所以减1
        实际消息数 = len(self.消息历史) - 1

        if 实际消息数 >= self.摘要阈值:
            print(f"📊 消息数 {实际消息数} >= 阈值 {self.摘要阈值}，开始压缩...")

            # 取前一半消息进行摘要
            压缩范围 = 实际消息数 // 2
            待压缩消息 = self.消息历史[1:1 + 压缩范围]

            # 用 AI 生成摘要
            摘要内容 = self._生成摘要(待压缩消息)

            # 更新摘要（追加）
            if self.摘要:
                self.摘要 += "\n" + 摘要内容
            else:
                self.摘要 = 摘要内容

            # 删除已压缩的消息
            self.消息历史 = [self.消息历史[0]] + self.消息历史[1 + 压缩范围:]

            print(f"✅ 压缩完成。剩余 {len(self.消息历史) - 1} 条消息")
            print(f"📝 当前摘要: {self.摘要[:100]}...")

    def _生成摘要(self, 消息列表: list[dict]) -> str:
        """用 AI 生成对话摘要"""
        对话文本 = "\n".join([
            f"{'用户' if 消['role'] == 'user' else 'AI'}: { 消['content']}"
            for 消 in 消息列表
        ])

        回复 = 客户端.chat.completions.create(
            model="gpt-4o-mini",
            messages=[
                {"role": "system", "content": "用3-5句话总结以下对话的要点，保留关键信息（用户偏好、已做的决定、未完成的事项）。"},
                {"role": "user", "content": 对话文本},
            ],
            temperature=0,
            max_tokens=200,
        )
        return 回复.choices[0].message.content

    def 获取统计(self) -> dict:
        return {
            "消息数": len(self.消息历史) - 1,
            "有摘要": bool(self.摘要),
            "摘要长度": len(self.摘要),
            "总tokens估算": sum(len(m["content"]) for m in self.消息历史) // 2,
        }


# ========== 使用示例
~~~

## Demo 6：MCP 协议 — AI 调用工具的标准化协议

### 学习目标

- 理解 MCP（Model Context Protocol）是什么
- 实现一个 MCP Server（提供工具）
- 实现一个 MCP Client（调用工具）
- 理解 MCP 和 Function Calling 的关系

### 6.1 MCP 是什么

~~~
MCP = Model Context Protocol（模型上下文协议）
由 Anthropic（Claude 的公司）提出的标准协议

解决的问题：
  之前：每个 AI 平台的工具调用格式不一样
    → OpenAI 用 tools/functions 格式
    → Claude 用 tool_use 格式
    → 每接一个 AI 平台，就要重写工具适配代码

  MCP 之后：统一的"插头"标准
    → 工具提供方写一次 MCP Server
    → AI 应用写一次 MCP Client
    → 任何支持 MCP 的 AI 都能用

类比：
  MCP = USB 接口标准
    → 以前：每个手机充电口不一样（Micro-USB, Lightning, ...）
    → 现在：统一用 USB-C
    → 你做一个 USB-C 的设备，所有电脑都能用

MCP 架构：
  ┌────────────┐     MCP 协议      ┌────────────┐
  │  MCP Host  │ ◄═══════════════► │  MCP Server │
  │  (AI应用)   │   JSON-RPC 2.0   │  (工具提供方) │
  └────────────┘                   └────────────┘
       │                                  │
       │ 提供 Tools                       │ 暴露 Tools
       │                                  │
  ┌────▼────┐                       ┌────▼────┐
  │ AI 模型  │                       │ 数据库   │
  │(GPT/Claude)│                    │ API/文件  │
  └─────────┘                       └─────────┘
~~~

### 6.2 实现 MCP Server

~~~python
# ========== demo6_MCP_Server.py
# MCP Server = 工具提供方
# 定义工具（就像写 API 接口），让 AI 可以调用

from mcp.server.fastmcp import FastMCP

# 创建 MCP Server
厨房MCP = FastMCP("餐厅工具服务")


# ========== 定义工具（用 @装饰器 注册）
# 每个工具函数 = 一个 AI 可以调用的能力
# 函数的 docstring 就是工具的描述（AI 靠这个理解工具用途）

菜品库 = {
    "宫保鸡丁": {"价格": 38.5, "分类": "热菜", "辣度": 3, "食材": "鸡肉、花生、辣椒"},
    "鱼香肉丝": {"价格": 28.0, "分类": "热菜", "辣度": 1, "食材": "猪肉、木耳、胡萝卜"},
    "麻婆豆腐": {"价格": 22.0, "分类": "热菜", "辣度": 4, "食材": "豆腐、牛肉末、花椒"},
    "红烧肉":   {"价格": 45.0, "分类": "热菜", "辣度": 0, "食材": "五花肉、酱油、冰糖"},
    "糖醋排骨": {"价格": 42.0, "分类": "热菜", "辣度": 0, "食材": "排骨、醋、糖"},
    "凉菜拼盘": {"价格": 18.0, "分类": "凉菜", "辣度": 0, "食材": "黄瓜、豆皮、花生"},
    "米饭":     {"价格": 3.0,  "分类": "主食", "辣度": 0, "食材": "大米"},
}


@厨房MCP.tool()
def 查询菜品信息(菜品名称: str) -> str:
    """查询指定菜品的详细信息，包括价格、分类、辣度和食材。

    参数：
        菜品名称: 要查询的菜品名称，如"宫保鸡丁"
    """
    if 菜品名称 in 菜品库:
        菜 = 菜品库[菜品名称]
        return f"{菜品名称}: ¥{菜['价格']}, 分类:{菜['分类']}, 辣度:{菜['辣度']}/5, 食材:{菜['食材']}"
    return f"未找到菜品'{菜品名称}'"


@厨房MCP.tool()
def 查询全部菜单() -> str:
    """获取餐厅的完整菜单，返回所有菜品的名称和价格。"""
    结果 = []
    for 名称, 信息 in 菜品库.items():
        结果.append(f"{名称}: ¥{信息['价格']} ({信息['分类']}, 辣度{信息['辣度']}/5)")
    return "\n".join(结果)


@厨房MCP.tool()
def 按条件推荐(最大辣度: int = 5, 最高价格: float = 100, 分类: str = "") -> str:
    """按条件筛选推荐菜品。

    参数：
        最大辣度: 最大辣度(0-5)，默认5(不限)
        最高价格: 最高价格，默认100(不限)
        分类: 菜品分类（热菜/凉菜/主食），默认空(不限)
    """
    结果 = []
    for 名称, 信息 in 菜品库.items():
        if 信息["辣度"] <= 最大辣度 and 信息["价格"] <= 最高价格:
            if not 分类 or 信息["分类"] == 分类:
                结果.append(f"{名称}: ¥{信息['价格']} (辣度{信息['辣度']})")
    if 结果:
        return "推荐菜品:\n" + "\n".join(结果)
    return "没有符合条件的菜品"


@厨房MCP.tool()
def 计算订单总价(菜品明细: str) -> str:
    """计算订单总价。

    参数：
        菜品明细: 格式如"宫保鸡丁x2,米饭x3"，用逗号分隔，x后面是数量
    """
    总价 = 0
    明细列表 = []
    for 项 in 菜品明细.split(","):
        部分 = 项.strip().split("x")
        名称 = 部分[0].strip()
        数量 = int(部分[1].strip())
        if 名称 in 菜品库:
            小计 = 菜品库[名称]["价格"] * 数量
            总价 += 小计
            明细列表.append(f"{名称} x{数量} = ¥{小计}")
        else:
            明细列表.append(f"{名称} x{数量} = 未找到")

    return f"订单明细:\n" + "\n".join(明细列表) + f"\n总价: ¥{round(总价, 2)}"


# ========== 启动 MCP Server
if __name__ == "__main__":
    print("🚀 MCP Server 启动中...")
    print("可用工具: 查询菜品信息, 查询全部菜单, 按条件推荐, 计算订单总价")
    厨房MCP.run(transport="stdio")  # stdio 模式：通过标准输入输出通信
~~~

### 6.3 实现 MCP Client

创建文件 `demo6_MCP_Client.py`：

~~~python
# ========== demo6_MCP_Client.py
# MCP Client = AI 应用端
# 连接 MCP Server，获取工具列表，让 AI 使用

import asyncio
import json
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
from openai import OpenAI
from dotenv import load_dotenv
import os

load_dotenv()

客户端 = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),
)


async def 主程序():
    # ========== 第一步：连接 MCP Server
    print("📡 连接 MCP Server...")

    # 指定 MCP Server 的启动命令
    服务器参数 = StdioServerParameters(
        command="python3",
        args=["demo6_MCP_Server.py"],  # 启动 MCP Server
    )

    async with stdio_client(服务器参数) as (读取, 写入):
        async with ClientSession(读取, 写入) as 会话:
            # 初始化连接
            await 会话.initialize()
            print("✅ MCP Server 已连接\n")

            # ========== 第二步：获取 MCP Server 提供的工具列表
            工具列表 = await 会话.list_tools()
            print(f"📦 发现 {len(工具列表.tools)} 个工具:")
            for 工具 in 工具列表.tools:
                print(f"  - {工具.name}: {工具.description[:50]}...")
            print()

            # ========== 第三步：把 MCP 工具转换为 OpenAI 的 tools 格式
            OpenAI工具清单 = []
            for 工具 in 工具列表.tools:
                OpenAI工具清单.append({
                    "type": "function",
                    "function": {
                        "name": 工具.name,
                        "description": 工具.description,
                        "parameters": 工具.inputSchema,  # MCP 工具自带 JSON Schema
                    },
                })

            # ========== 第四步：对话 + 自动调用 MCP 工具
            用户问题 = "我想吃不辣的菜，预算50以内，帮我推荐并算一下如果各来一份多少钱"
            print(f"👤 用户: {用户问题}\n")

            消息列表 = [
                {"role": "system", "content": "你是餐厅AI助手，用工具帮顾客查菜单、推荐菜品、计算价格。回复简洁。"},
                {"role": "user", "content": 用户问题},
            ]

            # AI 第一轮：决定调用什么工具
            回复 = 客户端.chat.completions.create(
                model="gpt-4o-mini",
                messages=消息列表,
                tools=OpenAI工具清单,
                tool_choice="auto",
            )

            消息对象 = 回复.choices[0].message

            if 消息对象.tool_calls:
                消息列表.append(消息对象)

                for 调用 in 消息对象.tool_calls:
                    函数名 = 调用.function.name
                    参数 = json.loads(调用.function.arguments)
                    print(f"🔧 AI 调用: {函数名}({参数})")

                    # 通过 MCP 协议调用远程工具
                    结果 = await 会话.call_tool(函数名, arguments=参数)
                    结果文本 = 结果.content[0].text if 结果.content else "无结果"
                    print(f"📦 结果: {结果文本}\n")

                    消息列表.append({
                        "role": "tool",
                        "tool_call_id": 调用.id,
                        "content": 结果文本,
                    })

                # AI 第二轮：基于工具结果生成最终回答
                最终回复 = 客户端.chat.completions.create(
                    model="gpt-4o-mini",
                    messages=消息列表,
                )
                print(f"🤖 AI: {最终回复.choices[0].message.content}")
            else:
                print(f"🤖 AI: {消息对象.content}")


# 运行
asyncio.run(主程序())
~~~

~~~python
from openai import OpenAI
from dotenv import load_dotenv
import os

load_dotenv()

客户端 = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),
)


class 对话管理器:
    def __init__(self, 系统提示: str, 摘要阈值: int = 20):
        self.系统提示 = 系统提示
        self.消息列表: list[dict] = []
        self.摘要: str = ""
        self.摘要阈值 = 摘要阈值

    def 添加用户消息(self, 内容: str):
        self.消息列表.append({"role": "user", "content": 内容})

    def 添加AI消息(self, 内容: str):
        self.消息列表.append({"role": "assistant", "content": 内容})

    def 添加工具消息(self, tool_call_id: str, 内容: str):
        self.消息列表.append({
            "role": "tool",
            "tool_call_id": tool_call_id,
            "content": 内容,
        })

    def 添加助手原始消息(self, 消息: dict):
        """添加包含 tool_calls 的助手消息"""
        self.消息列表.append(消息)

    def 获取完整消息(self) -> list[dict]:
        系统消息 = [{"role": "system", "content": self.系统提示}]
        if self.摘要:
            系统消息.append({"role": "system", "content": f"之前的对话摘要：{self.摘要}"})
        return 系统消息 + self.消息列表

    def 检查并压缩(self):
        if len(self.消息列表) >= self.摘要阈值:
            压缩数量 = len(self.消息列表) // 2
            待压缩 = self.消息列表[:压缩数量]

            对话文本 = "\n".join([
                f"{'用户' if m['role'] == 'user' else 'AI'}: {m.get('content', '[工具调用]')}"
                for m in 待压缩 if m['role'] in ('user', 'assistant') and m.get('content')
            ])

            回复 = 客户端.chat.completions.create(
                model="gpt-4o-mini",
                messages=[
                    {"role": "system", "content": "用3句话总结对话要点，保留用户偏好和关键决定。"},
                    {"role": "user", "content": 对话文本},
                ],
                temperature=0, max_tokens=150,
            )

            新摘要 = 回复.choices[0].message.content
            self.摘要 = f"{self.摘要}\n{新摘要}" if self.摘要 else 新摘要
            self.消息列表 = self.消息列表[压缩数量:]
~~~

**ai_engine.py（AI 引擎核心）：**

~~~python
# ========== ai_engine.py

import json
from openai import OpenAI
from dotenv import load_dotenv
import os
from memory import 对话管理器
from tools import 工具函数映射
from tools_schema import 工具清单

load_dotenv()

客户端 = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),
)

系统提示 = """你是"川味小馆"的 AI 点餐助手。

## 职责
- 帮顾客查看菜单、推荐菜品、计算价格
- 用工具查询菜品信息，不要编造信息
- 回复简洁热情，不超过3句话

## 约束
- 只推荐本店有的菜品（用查询菜单工具查看）
- 价格以工具返回的为准
- 如果顾客问非餐厅问题，礼貌引导回点餐"""


class AI引擎:
    def __init__(self, 会话ID: str):
        self.管理器 = 对话管理器(系统提示)
        self.会话ID = 会话ID

    async def 流式处理(self, 用户消息: str):
        """处理用户消息，yield SSE 数据块"""
        self.管理器.添加用户消息(用户消息)
        消息列表 = self.管理器.获取完整消息()

        # 第一轮：AI 决定是否调用工具
        回复 = 客户端.chat.completions.create(
            model="gpt-4o-mini",
            messages=消息列表,
            tools=工具清单,
            tool_choice="auto",
        )

        消息对象 = 回复.choices[0].message

        if 消息对象.tool_calls:
            # 保存 AI 的 tool_calls 消息
            self.管理器.添加助手原始消息(消息对象)

            # 执行所有工具调用
            for 调用 in 消息对象.tool_calls:
                函数名 = 调用.function.name
                参数 = json.loads(调用.function.arguments)

                yield f"data: {json.dumps({'类型': '工具调用', '函数': 函数名}, ensure_ascii=False)}\n\n"

                结果 = 工具函数映射[函数名](**参数)

                self.管理器.添加工具消息(
                    调用.id,
                    json.dumps(结果, ensure_ascii=False),
                )

            # 第二轮：基于工具结果流式回答
            消息列表 = self.管理器.获取完整消息()
            流 = 客户端.chat.completions.create(
                model="gpt-4o-mini",
                messages=消息列表,
                stream=True,
            )

            完整回答 = ""
            for 数据块 in 流:
                内容 = 数据块.choices[0].delta.content
                if 内容:
                    完整回答 += 内容
                    yield f"data: {json.dumps({'类型': '内容', '字符': 内容}, ensure_ascii=False)}\n\n"

            self.管理器.添加AI消息(完整回答)
        else:
            # AI 直接回答
            self.管理器.添加AI消息(消息对象.content)
            yield f"data: {json.dumps({'类型': '内容', '字符': 消息对象.content}, ensure_ascii=False)}\n\n"

        self.管理器.检查并压缩()
        yield f"data: {json.dumps({'类型': '完成'}, ensure_ascii=False)}\n\n"
~~~

## 高频面试题

### Q1：什么是 Function Calling？和 MCP 有什么区别？

~~~
Function Calling：
  OpenAI 提出的机制，让 AI 决定调用什么函数
  每个 AI 平台格式略有不同（OpenAI tools, Claude tool_use）
  适合：单个 AI 应用内部使用

MCP（Model Context Protocol）：
  Anthropic 提出的开放标准协议
  统一了工具定义和调用格式
  适合：工具需要被多个 AI 平台复用

关系：MCP 是"标准"，Function Calling 是"机制"
  → MCP Server 定义工具（标准化格式）
  → AI 应用把 MCP 工具转为 Function Calling 格式
  → AI 模型通过 Function Calling 决定调用哪个
  → 应用通过 MCP 协议执行调用
~~~

### Q2：Prompt 工程有哪些核心技巧？

~~~
1. System Prompt（角色设定）→ 4 要素：角色 + 职责 + 约束 + 风格
2. Few-Shot（给例子）→ 给 2-3 个输入输出例子，AI 就知道格式了
3. CoT（链式思考）→ 加一句"让我们一步步思考"，提升推理准确率
4. 结构化输出 → 要求输出 JSON + response_format 参数
5. Temperature → 0 确定性任务，0.7 日常对话，1.0+ 创意任务
~~~

### Q3：Agent 和普通的 AI 对话有什么区别？

~~~
普通 AI 对话：
  用户 → AI → 回答（纯靠模型知识，不能做实际操作）

AI Agent：
  用户 → AI → 思考 → 调用工具 → 获取结果 → 继续思考 → ... → 最终回答
  AI 具备自主决策能力，能决定什么时候该用什么工具

Agent = AI 模型 + 工具 + ReAct 循环 + 记忆系统
~~~

### Q4：AI 的"记忆"是怎么实现的？

~~~
AI 本身无状态，"记忆" = 把历史消息一起发过去

短期记忆：完整的对话历史（messages 数组）
长期记忆：摘要压缩（AI 总结之前的对话重点，删掉原文）

三层结构：
  system 消息 → 角色设定（不变）
  摘要消息   → 之前的对话重点（定期更新）
  最近消息   → 最近的对话内容（滚动窗口）
~~~

### Q5：Temperature 参数怎么选？

~~~
Temperature = 0：
  → 输出最确定，几乎每次一样
  → 适合：代码生成、数学计算、数据提取、Function Calling

Temperature = 0.7（推荐默认）：
  → 适度创意，变化自然
  → 适合：日常对话、客服、推荐

Temperature = 1.0+：
  → 高度随机，可能出彩也可能胡说
  → 适合：创意写作、头脑风暴

实际开发中，Function Calling 的场景建议 temperature=0
~~~

## 终极记忆卡片

1. **OpenAI API** → `OpenAI()` 创建客户端，`.chat.completions.create()` 发消息，`messages` 数组是核心
2. **messages 结构** → `system`（工作手册）+ `user`（用户说的）+ `assistant`（AI 说的）+ `tool`（工具结果）
3. **Temperature** → 0=确定（代码/计算），0.7=日常，1.0+=创意
4. **System Prompt** → 角色 + 职责 + 约束 + 风格，4 要素缺一不可
5. **Few-Shot** → 给 2-3 个例子，AI 就知道输出格式了
6. **CoT** → "让我们一步步思考"，提升推理准确率
7. **结构化输出** → 提示词要求 JSON + `response_format={"type": "json_object"}`
8. **Function Calling** → `tools` 定义工具清单，AI 自动决定调用哪个，你执行后把结果发回
9. **ReAct** → Thought → Action → Observation 循环，Agent 的核心工作模式
10. **记忆系统** → 对话历史（短期）+ 摘要压缩（长期），`messages` 数组就是"记忆"
11. **MCP** → AI 工具的标准化协议，Server 定义工具，Client 调用工具
