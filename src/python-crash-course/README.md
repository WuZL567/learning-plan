## 学习路径

### 第一步：阅读 JS vs Python 对照表（15 分钟）

打开 `01_deepseek_basic.py`，重点看：
1. 类和对象的对应关系
2. 函数定义的对应关系
3. 模板字符串的写法
4. 字典（dict）vs 对象（object）的区别

**关键记忆点**：
- `this` → `self`
- `constructor` → `__init__`
- `` `${var}` `` → `f'{var}'`
- `{key: value}` → `{'key': value}`（key 要加引号）

### 第二步：完成练习 1（15 分钟）

文件：`01_deepseek_basic.py`

1. 阅读代码，理解每一行
2. 回答练习题（写在注释里）
3. 完成动手练习（修改函数，增加 temperature 参数）

**验收标准**：能解释函数的每个部分对应 JS 的什么

### 第三步：完成练习 2（30 分钟）

文件：`02_class_encapsulation.py`

1. 理解 Python 类的写法
2. 对照 JS 的 class，找出对应关系
3. 回答练习题
4. 完成动手练习（增加 set_model 方法）

**验收标准**：能用 Python 类封装一个简单的 API 客户端

### 第四步：完成练习 3（30 分钟）

文件：`03_simple_multi_provider.py`

1. 理解继承和多态
2. 理解工厂函数的作用
3. 回答练习题
4. 完成动手练习（增加 GPTProvider）

**验收标准**：理解多 Provider 封装的设计思路

### 第五步：自测（30 分钟）

不看代码，尝试回答：

1. Python 如何定义一个类？构造函数叫什么？

## 常见问题

**Q1：我没有 DeepSeek API Key 怎么办？**  
A：用 mock 数据模拟，重点是理解代码结构，不是真调 API。

**Q2：我需要装 Python 环境吗？**  
A：建议装，但不强制。能看懂代码即可，实际运行是加分项。

**Q3：2 小时完不成怎么办？**  
A：可以延长到 3-4 小时，但不要超过 4 小时。如果 4 小时还完不成，说明当前方案不适合，需要重新调整。

**Q4：练习题不会做怎么办？**  
A：先尝试自己思考，实在想不出可以问导师，但要说明你的思考过程。
